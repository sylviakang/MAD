六組對照

左 C#・右 Dart

同一件事的兩種寫法並排。Dart 範例都已實際執行過，註解裡的值就是印出結果。

1

字串插值與格式

C# 用 $"{x}"；Dart 不用前綴，變數直接寫 $x，運算式才要 ${ }。

C#
int steps = 1500;
string name = "SK";
Console.WriteLine($"{name} 走了 {steps} 步，共 {steps * 0.04} kcal");
Console.WriteLine(3.14159.ToString("F2"));
Dart
final steps = 1500;
final name = 'SK';
print('$name 走了 $steps 步，共 ${steps * 0.04} kcal');
// SK 走了 1500 步，共 60.0 kcal
print(3.14159.toStringAsFixed(2)); // 3.14
2

字典取值與 null

C# 取不存在的鍵會丟例外；Dart 會回傳 null，所以一定要搭配 ??。

C#
var daily = new Dictionary<string, int> { ["Mon"] = 3000 };
// daily["Wed"] 會丟出 KeyNotFoundException
int wed = daily.TryGetValue("Wed", out var v) ? v : 0;
Dart
final daily = <String, int>{'Mon': 3000};
print(daily['Wed']);            // null，不會丟例外
final wed = daily['Wed'] ?? 0;  // 0
3

具名與選擇性參數

C# 呼叫時任何參數都能具名；Dart 只有寫在 { } 裡的參數才能具名，Flutter Widget 全是這種寫法。

C#
string Greet(string name, string prefix = "Hi", int times = 1)
    => string.Join(", ", Enumerable.Repeat($"{prefix} {name}", times));

Greet("SK", times: 2);
Dart
String greet(String name, {String prefix = 'Hi', int times = 1}) =>
    List.filled(times, '$prefix $name').join(', ');

greet('SK', times: 2);   // Hi SK, Hi SK
4

switch 表達式

兩者幾乎一樣，差別只在 switch 的位置與字串引號。

C#
string Level(int p) => p switch
{
    >= 100 => "達標",
    >= 50 => "過半",
    _ => "加油"
};
Dart
String level(int p) => switch (p) {
      >= 100 => '達標',
      >= 50 => '過半',
      _ => '加油',
    };
5

類別與屬性

Dart 沒有 public／private 關鍵字，名稱底線開頭就是私有；建立物件不用 new；欄位用 this.x 直接在建構子指定。

C#
public class Badge
{
    public string Title { get; }
    public int Target { get; }
    public int Current { get; set; }

    public Badge(string title, int target, int current = 0)
    {
        Title = title; Target = target; Current = current;
    }

    public bool Unlocked => Current >= Target;
}

var b = new Badge("初次一萬步", 10000, current: 12000);
Dart
class Badge {
  final String title;
  final int target;
  int current;

  Badge(this.title, this.target, {this.current = 0});

  bool get unlocked => current >= target;
}

final b = Badge('初次一萬步', 10000, current: 12000);
print(b.unlocked); // true
6

LINQ 與集合方法

名稱大多改成小寫；Select 對應 map；Sum、Max 沒有內建，要用 fold、reduce。

C#
var list = new List<int> { 300, 1200, 800, 500 };
var doubled = list.Select(s => s * 2).ToList();
int biggest = list.Max();
bool any = list.Any(s => s > 1000);
int total = list.Sum();
Dart
// 檔案開頭：import 'dart:math';
final list = <int>[300, 1200, 800, 500];
final doubled = list.map((s) => s * 2).toList(); // [600, 2400, 1600, 1000]
final biggest = list.reduce(max);                // 1200
final any = list.any((s) => s > 1000);           // true
final total = list.fold(0, (a, b) => a + b);     // 2800

類別、私有欄位與屬性

把左邊的 C# 改寫成 Dart
C#
public class Goal
{
    private int _steps;
    public int Target { get; }
    public Goal(int target) { Target = target; }
    public void Add(int s) { _steps += s; }
    public int Percent => Math.Min(_steps * 100 / Target, 100);
}

var g = new Goal(6000);
g.Add(4500);
Console.WriteLine(g.Percent);
Dart 預期輸出
75
寫完再打開：參考答案
import 'dart:math';

class Goal {
  int _steps = 0;
  final int target;
  Goal(this.target);
  void add(int s) => _steps += s;
  int get percent => min(_steps * 100 ~/ target, 100);
}

void main() {
  final g = Goal(6000);
  g.add(4500);
  print(g.percent);
}

05

switch 與迴圈

把左邊的 C# 改寫成 Dart
C#
int[] percents = { 120, 60, 10 };
foreach (var p in percents)
{
    string level = p switch
    {
        >= 100 => "達標",
        >= 50 => "過半",
        _ => "加油"
    };
    Console.WriteLine($"{p}% {level}");
}
Dart 預期輸出
120% 達標
60% 過半
10% 加油
寫完再打開：參考答案
for (final p in [120, 60, 10]) {
  final level = switch (p) {
    >= 100 => '達標',
    >= 50 => '過半',
    _ => '加油',
  };
  print('$p% $level');
}
