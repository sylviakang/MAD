repo 變成 ChangeNotifier

資料只有一份，改資料的地方也只有 repo。所以由 repo 負責喊一聲「我變了」，誰要更新就自己來聽。

class StepRepository extends ChangeNotifier {
  Future<void> add(DateTime time, int steps) async {
    if (steps <= 0) return;
    _records.add(StepRecord(time: time, steps: steps));
    notifyListeners();     // 先通知畫面
    await _save();         // 再慢慢寫檔
  }

  Future<void> setGoal(int goal) async {
    …
    notifyListeners();
    await _saveSettings();
  }
}
3

兩種聽法

成就頁整頁跟著 repo 變，用 ListenableBuilder 最簡單。首頁有動畫和自己的狀態，用 addListener，記得在 dispose 拿掉。

// 成就頁
@override
Widget build(BuildContext context) => ListenableBuilder(
  listenable: repo,
  builder: (context, _) => _build(context),
);

// 首頁
@override
void initState() {
  super.initState();
  repo.addListener(_onRepoChanged);
}
void _onRepoChanged() => setState(() {});

@override
void dispose() {
  repo.removeListener(_onRepoChanged);   // 有 add 就要有 remove
  …
}
4

裁判會改模擬器日期

題目附了「修改虛擬機系統時間.pdf」，代表裁判可能切換日期測試近 8 日和成就日期。首頁記住的「今天」要在 App 回到前景時重新檢查。

late final AppLifecycleListener _life;
DateTime _today = dateOnly(DateTime.now());

// initState
_life = AppLifecycleListener(onResume: _checkToday);

void _checkToday() {
  final t = dateOnly(DateTime.now());
  if (t == _today) return;
  setState(() {
    _today = t;
    _anchor = t;
    _selected = t;
  });
  _replay();
}

// dispose
_life.dispose();
