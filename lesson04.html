六個重點概念

跟著教練一起做

範例取自教練版完整首頁，已用 Flutter 3.47 通過 flutter analyze，並在 360×640 與 411×891 兩種尺寸測試沒有溢出。

1

Column 與 Row

主軸是排列方向（Column 是上下、Row 是左右），交叉軸是另一個方向。

Column(
  mainAxisAlignment: MainAxisAlignment.center,    // 上下置中
  crossAxisAlignment: CrossAxisAlignment.start,   // 靠左
  children: [
    Text('8,542', style: TextStyle(fontSize: 36)),
    SizedBox(height: 4),                          // 間距
    Text('步數'),
  ],
)
2

Expanded 分配空間

兩張卡片各佔一半；寫 flex: 2 就佔兩份。Row 裡的文字太長時也要包 Expanded，否則會出現黃黑條紋溢出警告。

Row(
  children: [
    Expanded(child: StatCard(value: '342', label: '卡路里 (kcal)')),
    SizedBox(width: 12),
    Expanded(child: StatCard(value: '6.2', label: '里程 (km)')),
  ],
)
3

Stack 疊層

圓形進度條和中間的數字是兩層疊在一起。alignment 決定子元件對齊位置，Positioned 可指定精確位置。

SizedBox(
  width: 220,
  height: 220,
  child: Stack(
    alignment: Alignment.center,
    children: [
      SizedBox.expand(
        child: CircularProgressIndicator(value: 0.85, strokeWidth: 16),
      ),
      Text('8,542', style: TextStyle(fontSize: 36)),
    ],
  ),
)
4

Container 與 BoxDecoration

卡片的白底、圓角、邊框、陰影都寫在 decoration。有 decoration 時，color 要寫在 BoxDecoration 裡，不能寫在 Container 上。

Container(
  padding: const EdgeInsets.all(16),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(16),
    border: Border.all(color: Color(0xFFE3E8F0)),
  ),
  child: Text('卡路里概況'),
)
5

StyleGuide 轉成程式

題本規定「未依 StyleGuide 設計，該畫面不給分」。先把顏色、字級集中成常數，整個專案只引用常數，不直接寫色碼。

// lib/theme.dart
class AppColors {
  static const primary = Color(0xFF00A396);   // 用 StyleGuide 取色替換
  static const background = Color(0xFFF4F7FB);
  static const subText = Color(0xFF8A94A6);
}

class AppText {
  static const big = TextStyle(fontSize: 36, fontWeight: FontWeight.bold);
  static const label = TextStyle(fontSize: 13, color: AppColors.subText);
}

final appTheme = ThemeData(
  scaffoldBackgroundColor: AppColors.background,
  colorScheme: ColorScheme.fromSeed(seedColor: AppColors.primary),
);
6

拆成自己的 Widget

重複出現的區塊寫成一個 StatelessWidget，用建構子參數傳入不同內容。程式短、好改，也是比賽節省時間的關鍵。

class StatCard extends StatelessWidget {
  const StatCard({super.key, required this.value, required this.label});

  final String value;
  final String label;

  @override
  Widget build(BuildContext context) {
    return Container(
      padding: const EdgeInsets.all(16),
      decoration: BoxDecoration(
        color: Colors.white,
        borderRadius: BorderRadius.circular(16),
      ),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(value, style: AppText.big),
          Text(label, style: AppText.label),
        ],
      ),
    );
  }
}
