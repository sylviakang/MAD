2

Matrix4：3D 旋轉

Transform 可以吃一個 4×4 矩陣。setEntry(3, 2, 小數字) 加上透視，rotateY 繞直的軸轉。沒有透視的話，看起來只是左右變窄。

Matrix4 badgeMatrix(double angle) => Matrix4.identity()
  ..setEntry(3, 2, AnimSpec.badgePerspective)
  ..rotateY(angle);

Transform(
  alignment: Alignment.center,    // 以中心為軸
  transform: badgeMatrix(angle),
  child: …,
)
3

過了 90 度就換面

Flutter 沒有「背面」這回事，轉過去看到的還是正面的反面。所以角度超過 90 度時，自己把 child 換成背面。

bool isBackSide(double angle) {
  final a = angle % (2 * pi);          // 轉超過一圈也能判斷
  return a > pi / 2 && a < 3 * pi / 2;
}

child: isBackSide(angle) ? backFace : frontFace,
4

背面要先轉 180 度

整張卡已經轉了 180 度，背面的字會左右相反。背面自己再轉 180 度，兩次加起來剛好正向。

child: isBackSide(angle)
    ? Transform(
        alignment: Alignment.center,
        transform: Matrix4.rotationY(pi),
        child: _back(),
      )
    : _front(),
5

開啟就播、點擊翻回

BadgeDialog 改成 StatefulWidget，controller 建立時直接 forward()。點徽章時看目前狀態決定往哪邊翻。

late final _c = AnimationController(
  vsync: this,
  duration: AnimSpec.badgeDuration,
)..forward();                          // 一打開就翻

late final _turn =
    CurvedAnimation(parent: _c, curve: AnimSpec.badgeCurve);

void _flip() => _c.isCompleted ? _c.reverse() : _c.forward();

// build
final angle = _turn.value * AnimSpec.badgeTurns * pi;
