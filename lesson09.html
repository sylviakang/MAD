1

Dialog 而不是 AlertDialog

AlertDialog 會先量內容的寬度，GridView 量不出來就直接報錯。版面自己排的 Dialog 沒有這個問題。

// ✗ 會出現紅色錯誤畫面
AlertDialog(content: GridView.count(crossAxisCount: 3, shrinkWrap: true, …))
// RenderShrinkWrappingViewport does not support
// returning intrinsic dimensions.

// ✓ 用 Dialog，裡面自己排
Dialog(
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: Column(
      mainAxisSize: MainAxisSize.min,
      children: [ /* 標題、輸入框、鍵盤、按鈕 */ ],
    ),
  ),
)
2

數字鍵盤

12 個鍵放進一個陣列，用 for 產生按鈕。shrinkWrap 讓格子只佔需要的高度，NeverScrollable 讓它不會跟著捲。

const keys = ['1', '2', '3', '4', '5', '6',
              '7', '8', '9', 'C', '0', '⌫'];

GridView.count(
  crossAxisCount: 3,
  shrinkWrap: true,
  physics: const NeverScrollableScrollPhysics(),
  childAspectRatio: 1.8,
  mainAxisSpacing: 8,
  crossAxisSpacing: 8,
  children: [
    for (final k in keys)
      OutlinedButton(onPressed: () => _press(k), child: Text(k)),
  ],
)
3

按鍵邏輯

所有按鍵都進同一個 _press，用字串累加。限制位數、避免 007 這種前導 0。

void _press(String key) {
  var t = _input.text;
  if (key == '⌫') {
    if (t.isNotEmpty) t = t.substring(0, t.length - 1);
  } else if (key == 'C') {
    t = '';
  } else if (t.length < 6) {
    t = t == '0' ? key : t + key;
  }
  setState(() => _input.text = t);
}
4

輸入框只給自製鍵盤用

評分有「步數輸入框」和「步數輸入鍵盤」兩項。用 readOnly 的 TextField，看起來是輸入框，又不會跳出系統鍵盤。

TextField(
  controller: _input,
  readOnly: true,       // 不跳系統鍵盤
  showCursor: true,
  textAlign: TextAlign.right,
  decoration: const InputDecoration(
    hintText: '0',
    border: OutlineInputBorder(),
  ),
)
5

新增按鈕

沒輸入時停用，避免存進 0 步。按下時把數字交回首頁，Dialog 自己不碰資料。

int get _steps => int.tryParse(_input.text) ?? 0;

FilledButton(
  onPressed: _steps > 0
      ? () => Navigator.pop(context, _steps)
      : null,               // null 就是停用
  child: const Text('新增'),
)

存到首頁選取的那一天

題目要求「儲存之步數需與首頁選擇之日期相關聯」。日期用 _selected，時分秒用現在，這樣長條圖的時段才有意義。

final steps = await showDialog<int>(
  context: context,
  builder: (_) => const AddStepsDialog(),
);
if (steps == null) return;

final now = DateTime.now();
final time = DateTime(_selected.year, _selected.month, _selected.day,
    now.hour, now.minute, now.second);
await repo.add(time, steps);
setState(() {});
