1

兩種通道

第 6 堂的 MethodChannel 是「問一次、答一次」。感測器每秒送幾十筆資料，要用 EventChannel，Dart 端拿到的是一個 Stream。

MethodChannel   Dart 問 → Kotlin 答（一次）
                invokeMethod('getFilesDir')

EventChannel    Dart listen → Kotlin 一直送
                events.success(…)  events.success(…)  …
                Dart cancel → Kotlin 停止
2

Kotlin：onListen 開始感測

在 configureFlutterEngine 裡建立 EventChannel，名稱和 Dart 端一模一樣。Dart 開始 listen 時才註冊感測器，不要一開 App 就註冊。

EventChannel(messenger, "movego/accel")
    .setStreamHandler(object : EventChannel.StreamHandler {
        override fun onListen(arguments: Any?, events: EventChannel.EventSink) {
            val sm = getSystemService(SENSOR_SERVICE) as SensorManager
            val sensor = sm.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)
            if (sensor == null) {
                events.error("NO_SENSOR", "這台裝置沒有加速度計", null)
                return
            }
            val listener = object : SensorEventListener {
                override fun onSensorChanged(e: SensorEvent) {
                    events.success(listOf(
                        e.values[0].toDouble(),
                        e.values[1].toDouble(),
                        e.values[2].toDouble()))
                }
                override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
            }
            sm.registerListener(listener, sensor, SensorManager.SENSOR_DELAY_GAME)
            sensorManager = sm
            accelListener = listener
        }
        override fun onCancel(arguments: Any?) { stopAccel() }
    })
3

Kotlin：一定要取消註冊

忘了 unregisterListener，離開頁面後感測器還在跑，耗電又會送資料給已經不存在的畫面。onDestroy 再保險一次。

private var sensorManager: SensorManager? = null
private var accelListener: SensorEventListener? = null

private fun stopAccel() {
    accelListener?.let { sensorManager?.unregisterListener(it) }
    accelListener = null
}

override fun onDestroy() {
    stopAccel()
    super.onDestroy()
}
4

Dart：把 List 包成類別

Kotlin 送來的是 List，裡面 3 個數字。包成 AccelSample 之後，畫面和下一堂的演算法都只看得到 x、y、z。

// lib/accel.dart
class AccelSample {
  const AccelSample(this.x, this.y, this.z);
  final double x, y, z;

  // 合力加速度：手機不動時約 9.8（地心引力）
  double get magnitude => sqrt(x * x + y * y + z * z);

  factory AccelSample.fromEvent(dynamic event) {
    final v = (event as List).cast<num>();
    return AccelSample(v[0].toDouble(), v[1].toDouble(), v[2].toDouble());
  }
}

class Accel {
  static const channel = EventChannel('movego/accel');
  static Stream<AccelSample> stream() =>
      channel.receiveBroadcastStream().map(AccelSample.fromEvent);
}
5

檢測頁：訂閱與取消

StreamSubscription 有值就代表正在檢測，按鈕文字直接看它。dispose 裡一定要 cancel，這也是 Kotlin 端 onCancel 會被呼叫的時機。

StreamSubscription<AccelSample>? _sub;
bool get _running => _sub != null;

void _start() {
  setState(() {
    _sub = Accel.stream().listen(
      (s) => setState(() => _last = s),
      onError: (Object e) => setState(() { _error = '$e'; _stop(); }),
    );
  });
}

void _stop() {
  _sub?.cancel();
  _sub = null;
}

@override
void dispose() {
  _stop();
  super.dispose();
}

不用手機也能測

模擬器右側 ⋯ → Virtual sensors 可以轉動、搖晃虛擬手機。單元測試則用 MockStreamHandler 假裝 Kotlin 端，確認 Dart 程式和取消的時機。

messenger.setMockStreamHandler(
  Accel.channel,
  MockStreamHandler.inline(
    onListen: (args, events) {
      events.success([0.0, 9.8, 0.0]);
      events.success([3.0, 4.0, 0.0]);
    },
    onCancel: (args) => cancels++,
  ),
);

final list = await Accel.stream().take(2).toList();
expect(list.last.magnitude, 5);
expect(cancels, 1);   // take 拿夠了會自動取消
