六個重點概念

跟著教練一起做

範例取自教練版專案，已用 Flutter 3.47 通過 flutter analyze，並用 widget test 逐一驗證切換、返回與三種關閉方式。

1

Navigator 是一疊卡片

push 把新頁面疊在最上面，pop 拿掉最上面那張。首頁永遠在最底下，所以按返回一定回得去。

// 前往趨勢分析頁
Navigator.push(
  context,
  MaterialPageRoute(builder: (_) => const TrendPage()),
);

// 在趨勢分析頁按返回
Navigator.pop(context);
2

外殼 MainShell

首頁和成就是「分頁」，不是 push。用一個 StatefulWidget 記住目前分頁，BottomNavigationBar 的 currentIndex 就是 Highlight。

class _MainShellState extends State<MainShell> {
  int _index = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: IndexedStack(
        index: _index,
        children: const [HomePage(), AchievementPage()],
      ),
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _index,                         // Highlight
        onTap: (i) => setState(() => _index = i),
        selectedItemColor: AppColors.primary,
        unselectedItemColor: AppColors.subText,
        items: const [ /* 見下一張卡 */ ],
      ),
    );
  }
}

4

帶結果回來

push 會回傳一個 Future，對方 pop 時帶的值就是結果。沒帶值（按返回、點空白）拿到的是 null，一定要先檢查。

// 首頁：等對方關掉
final steps = await showDialog<int>(
  context: context,
  builder: (_) => const AddStepsDialog(),
);
if (steps == null) return;   // 取消、關閉、點空白
debugPrint('新增 $steps 步');  // 第 9 堂改成存檔

// Dialog：按「新增」帶值回去
Navigator.pop(context, 100);
5

Dialog 的三種關閉

題目要求取消、關閉、點空白三種都能關（共 1 分）。點空白是 showDialog 的預設行為，不要自己把 barrierDismissible 改成 false。

AlertDialog(
  title: Row(
    children: [
      const Expanded(child: Text('輸入步數')),
      IconButton(                                    // 關閉
        onPressed: () => Navigator.pop(context),
        icon: const Icon(Icons.close),
      ),
    ],
  ),
  actions: [
    TextButton(                                      // 取消
      onPressed: () => Navigator.pop(context),
      child: const Text('取消'),
    ),
    FilledButton(                                    // 新增
      onPressed: () => Navigator.pop(context, 100),
      child: const Text('新增'),
    ),
  ],
)
