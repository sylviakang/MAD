六個重點概念

跟著教練一起做

Dart 範例已用 Flutter 3.47 通過 flutter analyze，並用模擬的 Kotlin 端測試成功、錯誤與缺方法三種情況。Kotlin 範例請在模擬器上實際執行確認。

1

為什麼需要通道

比賽不能用 path_provider 套件，Dart 自己不知道 App 的私有資料夾在哪。這個路徑 Android 才知道，所以請 Kotlin 告訴我們。

// Kotlin 一行就拿得到
filesDir.absolutePath
// → /data/user/0/tw.mad08.movego/files

// Dart 沒有對應的內建 API，
// 所以要透過 MethodChannel 去問 Kotlin
2

Kotlin 端：註冊通道

打開 android/app/src/main/kotlin/…/MainActivity.kt，覆寫 configureFlutterEngine。package 那一行不要動，它要跟資料夾路徑一致。

class MainActivity : FlutterActivity() {

    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)

        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, "movego/storage")
            .setMethodCallHandler { call, result ->
                when (call.method) {
                    "getFilesDir" -> result.success(filesDir.absolutePath)
                    else -> result.notImplemented()
                }
            }
    }
}
3

Dart 端：包成一個類別

通道名稱兩邊一個字都不能差。把呼叫包在 NativeStorage 裡，其他程式只要 await NativeStorage.filesDir()。

import 'package:flutter/services.dart';

class NativeStorage {
  static const _channel = MethodChannel('movego/storage');

  static Future<String> filesDir() async {
    final path = await _channel.invokeMethod<String>('getFilesDir');
    return path!;
  }
}
4

在 runApp 之前呼叫

main 裡要在 runApp 之前用通道，第一行一定要先 ensureInitialized，否則會直接閃退。

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final dir = await NativeStorage.filesDir();
  debugPrint('filesDir = $dir');
  runApp(const MoveGoApp());
}
5

帶參數與回報錯誤

Dart 傳 Map，Kotlin 用 call.argument 取出。缺參數時用 result.error 回報，Dart 端收到 PlatformException。

// Kotlin
"fileExists" -> {
    val name = call.argument<String>("name")
    if (name == null) {
        result.error("NO_NAME", "缺少檔名", null)
    } else {
        result.success(File(filesDir, name).exists())
    }
}

// Dart
static Future<bool> fileExists(String name) async {
  final ok = await _channel.invokeMethod<bool>('fileExists', {'name': name});
  return ok ?? false;
}
