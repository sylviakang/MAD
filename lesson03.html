├─ android/app/
│  ├─ build.gradle.kts       ← applicationId（套件名稱）
│  └─ src/main/AndroidManifest.xml  ← android:label（App 名稱）

└─ 08_MoveGo.apk             ← 交件前複製到這裡
2

最小的 Flutter App

runApp 放進根 Widget；MaterialApp 提供主題與導覽；Scaffold 提供 AppBar、內容區、FAB 的位置。

import 'package:flutter/material.dart';

void main() {
  runApp(const MoveGoApp());
}

class MoveGoApp extends StatelessWidget {
  const MoveGoApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,  // 拿掉右上角 DEBUG
      home: Scaffold(
        body: Center(child: Text('首頁')),
      ),
    );
  }
}

題本規定 App 名稱為「MoveGo_XX」，XX 是崗位號碼。名稱錯誤扣 1 分。改完要重新安裝才會生效。

4

登記 assets

pubspec.yaml 用縮排表示層級，assets 要在 flutter: 底下縮排兩格。登記資料夾時結尾要加斜線。

# pubspec.yaml
flutter:
  uses-material-design: true
  assets:
    - assets/icons/
    - assets/data/

# 程式裡使用
Image.asset('assets/icons/ic_analysis.png', width: 28)
5

StatefulWidget 與 setState

會變動的資料放在 State 裡；改資料一定要包在 setState 裡，畫面才會重畫。

class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() => _HomePageState();
}

class _HomePageState extends State<HomePage> {
  int _steps = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(child: Text('今日步數：$_steps')),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => _steps += 100),
        child: const Icon(Icons.add),
      ),
    );
  }
}

常用指令

在 VS Code 終端機執行。Hot Reload 保留狀態、只更新畫面；Hot Restart 會從 main 重新開始，狀態歸零。

flutter create --org tw.mad08 --platforms android movego
flutter emulators                 # 列出模擬器
flutter emulators --launch <名稱>  # 開啟模擬器
flutter run                       # r = Hot Reload，R = Hot Restart，q = 離開
flutter build apk --release

# Windows：把 APK 複製到專案根目錄並改名
copy build\app\outputs\flutter-apk\app-release.apk 08_MoveGo.apk
