變更說明

範例取自教練版

教練版已用 Flutter 3.47 改完這七處，flutter analyze 沒有問題，60 個測試全部通過。下面是每一處要改的地方。

1

換算：只改 calc.dart

如果當初卡路里、里程只寫在一個地方，這一步 1 分鐘就改完。到處寫 0.04 的人要一個一個找。

// 模擬賽二：每一步 0.05 kcal、0.0007 km
double kcalOf(int steps) => steps * 5 / 100;
double kmOf(int steps) => steps * 7 / 10000;
2

時段：三個地方要一起改

時段判斷、時段陣列長度、X 軸文字。長條圖用 values.length 畫，就不必再改。

// step_repository.dart
int slotOf(DateTime t) {
  final m = t.hour * 60 + t.minute;
  if (m <= 8 * 60) return 0;
  if (m <= 16 * 60) return 1;
  return 2;
}
final slots = [0, 0, 0];                 // slotsOfDay

// bar_chart.dart
const slotLabels = ['00:00\n～08:00', '08:01\n～16:00', '16:01\n～23:59'];
3

Y 軸：N = 5

演算法不變，只是 N 從 4 變 5。驗算一次：427.1 ÷ 5 = 85.42，Mag 10，Norm 8.542，B = 10，Tick 100，Ymax 500，共 6 條格線。

YAxis niceAxis(double dMax, {int n = 5}) { … }

// 427.1 → YAxis(max: 500.0, tick: 100.0)
// 250   → 250 / 5 = 50 → Norm 5 → B 5 → Tick 50 → Ymax 250
4

搖晃與成就

隨機數改一個數字。成就清單直接換 json，程式寫對的話不用改任何一行。

return 2 + _random.nextInt(3);           // 2、3、4

// assets/achievements.json（題目提供，這裡節錄新增的兩筆）
{"id": 1, "condition": 2000, …}
{"id": 5, "condition": 30000,
 "image": "assets/icons/ic_badge1.png",
 "radial": ["0xFFFDE68A", "0xFFF59E0B", "0xFF78350F"]}
5

徽章：X 軸、一圈半

rotateY 換成 rotateX，背面的修正也要換成 rotationX。轉幾圈只改 AnimSpec。一圈半是 3 個半圈，結束時剛好在背面。

static const badgeTurns = 3.0;           // 3 個半圈 = 540 度

Matrix4 badgeMatrix(double angle) => Matrix4.identity()
  ..setEntry(3, 2, AnimSpec.badgePerspective)
  ..rotateX(angle);

// 背面
transform: Matrix4.rotationX(pi),

Text(fmtYmd(widget.unlockedAt).replaceAll('.', '/'))   // 2026/03/02
