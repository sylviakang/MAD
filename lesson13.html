2

資料值轉成 y 座標

畫布的 y 往下變大，圖表的數值往上變大，所以要翻過來。這一行是整張圖最重要的公式。

// 0 在 plot 底部，yMax 在 plot 頂部
double yOf(double v) => plot.bottom - plot.height * (v / yMax);

// 例：plot 從 y=8 到 y=144，高 136，yMax = 150
// yOf(0)   = 144        （底部）
// yOf(75)  = 144 - 68 = 76
// yOf(150) = 8          （頂部）
3

格線與 Y 軸數字

用整數 k 數格子，數值 = k × tick。用小數一直加 tick，加到最後可能變成 149.99999 而少畫一條線。

final count = (yMax / tick).round();
for (var k = 0; k <= count; k++) {
  final v = k * tick;
  final y = yOf(v);
  canvas.drawLine(Offset(plot.left, y), Offset(plot.right, y), grid);
  _text(canvas, _num(v), Offset(plot.left - 6, y), align: _Align.right);
}
4

TextPainter 畫文字

先 layout 才知道文字寬高，再依對齊方式算出左上角。Y 軸文字靠右、垂直置中；X 軸文字水平置中、貼在上方。

final tp = TextPainter(
  text: TextSpan(text: s, style: const TextStyle(fontSize: 10)),
  textAlign: TextAlign.center,
  textDirection: TextDirection.ltr,
)..layout();

// Y 軸：右邊對齊 at，垂直置中
tp.paint(canvas, at - Offset(tp.width, tp.height / 2));

// X 軸：水平置中，上緣對齊 at
tp.paint(canvas, at - Offset(tp.width / 2, 0));

長條

每個時段佔 plot 寬度的四分之一，長條寬度取其中 45%、置中。只有上方兩角是圓的。

final slot = plot.width / values.length;
final barW = slot * 0.45;
for (var i = 0; i < values.length; i++) {
  final cx = plot.left + slot * (i + 0.5);       // 這一格的中心
  final v = (values[i] * progress).clamp(0.0, yMax);
  if (v > 0) {
    final rect = Rect.fromLTRB(
        cx - barW / 2, yOf(v), cx + barW / 2, plot.bottom);
    canvas.drawRRect(
      RRect.fromRectAndCorners(rect,
          topLeft: const Radius.circular(6),
          topRight: const Radius.circular(6)),
      bar,
    );
  }
}

// 第 13 堂暫用的 Y 軸：最大值往上取到 50 的倍數、切 5 格
(double, double) simpleAxis(List<double> values) {
  final max = values.fold(0.0, (a, b) => a > b ? a : b);
  final yMax = max <= 0 ? 50.0 : (max / 50).ceil() * 50.0;
  return (yMax, yMax / 5);
}
