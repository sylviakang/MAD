模擬賽一完整題目

今天照比賽的方式，從空白專案開始，2.5 小時做出完整的 MoveGo。不看筆記、不問隊友，時間到就停手。做完兩人交換，用評分表幫對方打分數。這一次的分數就是下一堂之前要補強的清單。

時間150 分鐘
從零開始flutter create
互評101 分評分表

今天的 180 分鐘（延長一小時）

說明0–10 分
限時作答10–160 分
互評160–180 分

作答時只能看題本、StyleGuide 和題目提供的檔案，跟比賽現場一樣。

開賽前 5 分鐘

5 分鐘・不寫程式

開始計時前做完這五件事，不寫任何程式。

  1. 崗位號碼是多少？App 名稱、APK 檔名各是什麼？
  2. 打開 StyleGuide，把主色、背景色、文字色抄下來
  3. 題目給的檔案全部複製進 assets，數一數有幾個
  4. 五支動畫影片各看一次，各寫一句重點
  5. 跟隊友確認：時間到前 5 分鐘一定要 build apk

六個賽前提醒

開賽前看一次

這六段是最容易寫錯、又最花時間的地方。開始作答後就不能再看，賽前五分鐘看一次就好。

Kotlin 兩個通道

MethodChannel 問路徑，EventChannel 送加速度。名稱兩邊一字不差。

MethodChannel(messenger, "movego/storage")
    .setMethodCallHandler { call, result ->
        when (call.method) {
            "getFilesDir" -> result.success(filesDir.absolutePath)
            else -> result.notImplemented()
        }
    }
EventChannel(messenger, "movego/accel")
    .setStreamHandler(object : EventChannel.StreamHandler {
        override fun onListen(a: Any?, events: EventChannel.EventSink) { … }
        override fun onCancel(a: Any?) { stopAccel() }
    })
3

日期與換算

日期只比年月日。卡路里、里程先乘整數再除。

DateTime dateOnly(DateTime d) => DateTime(d.year, d.month, d.day);
// 近 8 日：T、T-1 … T-7
[for (var i = 0; i < 8; i++) DateTime(t.year, t.month, t.day - i)]
// 本週一
DateTime(t.year, t.month, t.day - (t.weekday - 1))
double kcalOf(int s) => s * 4 / 100;      // 0.04
double kmOf(int s) => s * 6 / 10000;      // 0.0006
4

Y 軸演算法

log10 會有誤差，floor 前加一點點；除完再 ceil 前減一點點。

final raw = dMax / n;
final mag = pow(10, (log(raw) / ln10 + 1e-9).floor()).toDouble();
final norm = raw / mag;
final b = norm <= 1.5 ? 1 : norm <= 3 ? 2 : norm <= 7 ? 5 : 10;
final tick = b * mag;
final max = (dMax / tick - 1e-9).ceil() * tick;
5

搖晃偵測

高峰只算一次，再加冷卻時間。

if (s.magnitude <= threshold) { _above = false; return 0; }
if (_above) return 0;
_above = true;
if (_last != null && at.difference(_last!) < cooldown) return 0;
_last = at;
return 1 + _random.nextInt(3);
6

動畫只調一個檔

所有時間、曲線、錯開比例放在 AnimSpec，對照影片時只改這裡。

class AnimSpec {
  static const ringDuration = Duration(milliseconds: 1200);   // progress
  static const recentStagger = 0.06;                           // progress_recent
  static const barDuration = Duration(milliseconds: 1000);    // bar_increase
  static const runDuration = Duration(milliseconds: 1200);    // run
  static const badgeDuration = Duration(milliseconds: 900);   // badge_rotate
}
