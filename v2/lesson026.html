?? ：是 null 就用預設值

新增 lesson026.dart。A ?? B：A 不是 null 就用 A，是 null 就用 B。結果一定不是 null，可以放心使用。

  ⟦greet('王小明', null);⟧
  ⟦greet('王小明', '阿明');⟧
}

⟦void greet(String name, String? nickname) {⟧
⟦  print('嗨，${nickname ?? name}');⟧
⟦}⟧

??= ：還沒有值才給

x ??= 值; 的意思是「如果 x 是 null，就把值給它；已經有值就不動」。適合用來設定預設值：沒傳目標就用 10000，有傳就照傳進來的。

void main() {
  ⟦showGoal(null);⟧
  ⟦showGoal(8000);⟧
}

⟦void showGoal(int? goal) {⟧
⟦  goal ??= 10000;⟧
⟦  print('目標：$goal');⟧
⟦}⟧
執行結果
$ dart run lesson026.dart
目標：10000
目標：8000
3

?. ：不是 null 才呼叫

s?.length：s 不是 null 就取 length；s 是 null 就整個變成 null，不會當掉。常跟 ?? 一起用：s?.length ?? 0。

void main() {
  ⟦showMotto('每天一萬步');⟧
  ⟦showMotto(null);⟧
}

⟦void showMotto(String? motto) {⟧
⟦  print(motto?.length);⟧
⟦  print('簽名 ${motto?.length ?? 0} 個字');⟧
⟦}⟧

! 的危險，以及完成資料卡

x! 是「我保證 x 不是 null」，Dart 就不檢查了。保證錯了，程式會在執行時當掉（看下面的卡住了）。所以能用 ??、?. 或 if 的地方，就不要用 !。

最後用安全的寫法完成資料卡，三個欄位都沒填也印得出來。

void main() {
  ⟦printCard(name: '王小明', nickname: '阿明', heightCm: 172.5);⟧
  ⟦print('');⟧
  ⟦printCard(name: '林小華');⟧
}

⟦void printCard({⟧
⟦  required String name,⟧
⟦  String? nickname,⟧
⟦  double? heightCm,⟧
⟦  String? motto,⟧
⟦}) {⟧
⟦  print('===== 使用者資料卡 =====');⟧
⟦  print('名字：$name');⟧
⟦  print('暱稱：${nickname ?? '（未填）'}');⟧
⟦  print('身高：${heightCm?.toStringAsFixed(1) ?? '--'} cm');⟧
⟦  print('簽名：${motto ?? '這個人很懶，什麼都沒寫'}');⟧
⟦}⟧

沒有 required 的命名參數：型別加 ?，呼叫時不給就是 null。所以 printCard(name: '林小華') 只給名字也可以。
