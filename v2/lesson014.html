對照表

用索引的 for 迴圈跟 C 一模一樣。Dart 另外有 for-in，等於 C++ 的 for (int x : s)、C# 的 foreach，不用管索引就能一個一個拿出來。

要做的事C / C++C#Dart / Flutter
用索引走訪for (int i = 0; i < 7; i++)for (int i = 0; i < s.Length; i++)for (var i = 0; i < s.length; i++)
一個一個拿★for (int x : s) // C++foreach (int x in s)for (final x in s)
條件寫錯★i <= 7 讀到亂碼例外i <= s.length 會 RangeError
邊走邊改s[i] = 0;s[i] = 0;s[i] = 0; // for-in 不能改
長條用迴圈印 *new string('*', n)'■' * n

★ 黃底＝跟 C/C# 不一樣、最容易寫錯的地方。

for-in：一個一個拿出來

如果不需要知道「第幾個」，用 for (final s in steps) 最簡單：每一圈 s 就是 List 裡的下一個值。這裡用它算出一週總步數。

void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  ⟦var total = 0;⟧
  ⟦for (final s in steps) {⟧
  ⟦  total += s;⟧
  ⟦}⟧
  ⟦print('一週總共 $total 步');⟧
}
卡住了？看這裡

想在 for-in 裡把值改掉是不行的，s 只是拿出來的複本，而且是 final：

The final variable 's' can only be set once.

完成：一週步數表

  1. 每 1000 步畫一格：'■' * (steps[i] ~/ 1000)。
  2. 達標（≥ 10000）的天，後面加上 ✔。
  3. 最後印出總步數。
void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  final days = ['一', '二', '三', '四', '五', '六', '日'];
  ⟦const goal = 10000;⟧
  ⟦var total = 0;⟧
  ⟦print('==== 一週步數表 ====');⟧
  for (var i = 0; i < steps.length; i++) {
    final s = steps[i].toString().padLeft(6);
    ⟦final bar = '■' * (steps[i] ~/ 1000);⟧
    ⟦final mark = steps[i] >= goal ? ' ✔' : '';⟧
    print('星期${days[i]} $s ⟦$bar$mark⟧');
    ⟦total += steps[i];⟧
  }
  ⟦print('總步數：$total');⟧
}

用索引走訪for (var i = 0; i < s.length; i++) { print(s[i]); }
for-infor (final x in s) { print(x); }
怎麼選

要索引或要改值用 for；只讀值用 for-in

條件

i < s.length，不要寫 <=

倒著走for (var i = s.length - 1; i >= 0; i--)
長條'■' * (n ~/ 1000)
