跳脫字元：\n、\t、\'、\$

新增 lesson006.dart。反斜線 \ 後面接一個字，代表「特別的字元」，規則跟 C 一樣。Dart 多了一個：\$ 代表錢字號本身。

void main() {
  ⟦print('第一行\n第二行');⟧
  ⟦print('姓名\t小明');⟧
  ⟦print('It\'s MoveGo');⟧
  ⟦print('獎金 \$100');⟧
}
卡住了？看這裡

忘了在 It's 的單引號前加反斜線，Dart 以為字串在 It 就結束了：

Expected to find ','.

$ 後面直接接數字，Dart 以為你要插入變數：

Expected an identifier.
執行結果
$ dart run lesson006.dart
第一行
第二行
姓名	小明
It's MoveGo

多行字串：用 ''' 包起來

三個單引號 ''' 可以包住很多行文字，換行會照原樣印出來，不用一直寫 \n。插值 $name 在裡面一樣能用。

void main() {
  final name = '小明';
  ⟦print('''===== 個人資料卡 =====
姓名：$name
====================''');⟧
}

小提醒：多行字串裡的空白也會照印。第二行、第三行要從最左邊開始寫，不要為了好看而縮排。

卡住了？看這裡

結尾只寫了兩個單引號 '' 或一個 '，字串就關不起來：

Unterminated string literal.
執行結果
$ dart run lesson006.dart
===== 個人資料卡 =====
姓名：小明
====================
3

padLeft：讓數字靠右對齊

  • s.padLeft(6)：字串不足 6 個字時，左邊補空白。
  • s.padLeft(2, '0')：左邊補 0，時間常用，例如 7 變成 07。
  • padLeft 是字串的方法，數字要先 toString()。
void main() {
  ⟦final steps = 6500;⟧
  ⟦final goal = 10000;⟧
  ⟦print('今日 ${steps.toString().padLeft(6)} 步');⟧
  ⟦print('目標 ${goal.toString().padLeft(6)} 步');⟧
  ⟦print('7'.padLeft(2, '0'));⟧
  ⟦print('MoveGo'.length);⟧
}

對照 C：這就是 printf 的 %6d。最後一行的 length 是字串長度，跟 C++ 的 s.length() 一樣，只是 Dart 不用加括號。

卡住了？看這裡

直接對數字呼叫 padLeft 會出錯，要先轉成字串：

The method 'padLeft' isn't defined for the type 'int'.
執行結果

文字轉數字：完成資料卡

  1. 假設資料是使用者打字輸入的，所以先用字串存放。
  2. 用 int.parse 和 double.parse 轉成數字，才能計算。
  3. 計算結果用 toStringAsFixed 和 padLeft 排整齊。
void main() {
  ⟦final nameText = '小明';⟧
  ⟦final ageText = '16';⟧
  ⟦final heightText = '172.8';⟧
  ⟦final stepsText = '6500';⟧
  const goal = 10000;

  ⟦final age = int.parse(ageText);⟧
  ⟦final heightM = double.parse(heightText) / 100;⟧
  ⟦final steps = int.parse(stepsText);⟧
  final percent = steps / goal * 100;

  print('''===== 個人資料卡 =====
姓名：$nameText（$age 歲）
身高：${heightM.toStringAsFixed(2).padLeft(6)} 公尺
步數：${steps.toString().padLeft(6)} 步
目標：${goal.toString().padLeft(6)} 步
達成：${percent.toStringAsFixed(1).padLeft(6)} %
====================''');
}

為什麼要轉？之後在 App 裡用輸入框（TextField）拿到的資料都是字串，一定要先轉成數字才能算。單元 9 還會學到「輸入亂打也不會當掉」的 tryParse。

卡住了？看這裡

字串不是整數的樣子，int.parse 會在執行時當掉。例如 int.parse('172.8')：

FormatException: Invalid radix-10 number (at character 1)
