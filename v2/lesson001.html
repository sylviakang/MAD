跟著做：4 個小步驟

每步做完都要執行看看

每一步只改一個地方。黃色底的程式是這一步新加的，做完按 Ctrl+S 存檔，看看畫面有沒有變，再勾「做完了」。

1

確認 Flutter 裝好了

  1. 打開 VS Code。
  2. 按 Ctrl+`（數字 1 左邊那個鍵）打開終端機。
  3. 輸入 flutter doctor 按 Enter，等它跑完。

看什麼？每一行前面的 [✓] 代表沒問題。只要 Flutter、Android toolchain、VS Code 三行是 [✓] 就可以繼續。

卡住了？看這裡

出現「flutter 不是內部或外部命令」：電腦找不到 Flutter。先把 VS Code 整個關掉再開一次，還是不行就請老師幫忙設定路徑。

'flutter' 不是內部或外部命令、可執行的程式或批次檔。

Android toolchain 那行是 [!] 或 [✗]：通常是授權還沒同意。輸入下面這行，一路按 y 再 Enter。

flutter doctor --android-licenses

2

建立第一個專案

  1. 按 Ctrl+Shift+P 打開指令面板，輸入 Flutter: New Project。
  2. 選 Application，再選一個放專案的資料夾。
  3. 專案名稱輸入 hello_app 按 Enter，等右下角跑完。

專案裡最重要的檔案是 lib/main.dart，就像 C 的 main.cpp。之後所有程式都寫在 lib 資料夾裡，其他資料夾先不用管。

卡住了？看這裡

名稱有大寫、空白、中文或數字開頭，Flutter 會拒絕。改成全小寫、用底線連接，例如 my_first_app。

"MyApp" is not a valid Dart package name. Try "myapp" instead.
專案資料夾
hello_app/
├ android/
├ lib/
│  └ main.dart   ← 寫程式的地方
├ test/
└ pubspec.yaml
3

讓 App 跑起來

  1. 看 VS Code 右下角，點一下裝置名稱，選模擬器或用 USB 接上的手機。
  2. 打開 lib/main.dart。
  3. 按 F5。第一次要等 1～3 分鐘，這是正常的。
  4. App 出現後按右下角的 +，數字會加 1。
卡住了？看這裡

右下角顯示 No Device：模擬器還沒開，或手機沒開「USB 偵錯」。請老師協助開啟。

No supported devices connected.

等了很久一直在跑：第一次執行要下載與編譯 Android 的東西，等它跑完就好，第二次會快很多。
