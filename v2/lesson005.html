var：讓 Dart 自己判斷型別

新增 lesson005.dart。用 var 宣告時不用寫型別，Dart 看等號右邊的值就知道是 int。之後可以改值，但型別不能改。

void main() {
  ⟦var steps = 6500;⟧
  print(steps);
  ⟦steps = 7000;⟧
  print(steps);
}

final 和 const：不會變的值

  • const：寫程式時就知道、永遠不變的值，例如目標步數 10000。
  • final：給一次值之後就不能改，例如使用者的名字。
  • var：會一直變的值，例如今天的步數。

先把 main 裡面換成下面這樣，再自己試著加一行 goal = 5;，看看會發生什麼事。

void main() {
  ⟦const goal = 10000;⟧
  ⟦final name = '小明';⟧
  print(name);
  print(goal);
}

怎麼選？先想「這個值會不會變」：會變用 var；不會變用 final；連寫程式時就確定的數字用 const。不確定時先用 final，Dart 會在你改它時提醒你。

卡住了？看這裡

改 const 的值會出錯：

Constant variables can't be assigned a value after initialization.

改 final 的值也會出錯：

The final variable 'name' can only be set once.
執行結果
$ dart run lesson005.dart
小明
10000
3

字串插值：把變數寫進字串

  • 單一個變數：在名字前加 $，例如 '$name'。
  • 有運算或小數點：要用 ${ } 包起來，例如 '${age + 1}'。

插值會自動把數字變成字串，不用再寫 toString()。

void main() {
  final name = '小明';
  ⟦final age = 16;⟧
  ⟦var steps = 6500;⟧
  const goal = 10000;
  ⟦print('姓名：$name（$age 歲）');⟧
  ⟦print('明年就 ${age + 1} 歲');⟧
  ⟦print('今日步數：$steps / $goal 步');⟧
}
卡住了？看這裡

寫成 '明年 $age+1 歲' 不會出錯，但會印出「明年 16+1 歲」。有運算一定要加大括號：${age + 1}。

明年 16+1 歲
執行結果
$ dart run lesson005.dart

明年就 17 歲

小數只留幾位：完成資料卡

  1. 用 final 算出公尺和達成率。
  2. 用 toStringAsFixed(2) 只留 2 位小數，它會四捨五入，結果是字串。
  3. 因為有 . 呼叫方法，要放在 ${ } 裡。
void main() {
  final name = '小明';
  final age = 16;
  ⟦final heightCm = 172.8;⟧
  var steps = 6500;
  const goal = 10000;

  ⟦final heightM = heightCm / 100;⟧
  ⟦final percent = steps / goal * 100;⟧

  ⟦print('===== 個人資料卡 =====');⟧
  ⟦print('姓名：$name（$age 歲）');⟧
  ⟦print('身高：${heightM.toStringAsFixed(2)} 公尺');⟧
  ⟦print('今日步數：$steps / $goal 步');⟧
  ⟦print('目標達成：${percent.toStringAsFixed(1)}%');⟧
  ⟦print('====================');⟧
}

謎底揭曉：上一堂的 1.7280000000000002 是電腦存小數的誤差。只要顯示時用 toStringAsFixed(2)，就會變成 1.73。MoveGo 裡的卡路里和公里數，全都靠這個方法顯示。

卡住了？看這裡

寫成 '$heightM.toStringAsFixed(2)' 會印出「1.7280000000000002.toStringAsFixed(2)」，因為沒有大括號時，$ 只吃到變數名字。

執行結果
