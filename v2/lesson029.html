getter：算出來的值

bool get reached => steps >= goal; 寫法像函式，但使用時像欄位：a.reached，不用括號。適合「由其他欄位算出來、沒有參數」的值。

void main() {
  final a = StepRecord(date: '11/10', steps: 6500);
  final b = StepRecord(date: '11/11', steps: 6500, goal: 6000);
  ⟦print('${a.date} 達標了嗎？${a.reached}');⟧
  ⟦print('${b.date} 達標了嗎？${b.reached}');⟧
  ⟦print('${a.date} ${a.km.toStringAsFixed(2)} 公里');⟧
}

class StepRecord {
  final String date;
  final int steps;
  final int goal;

  StepRecord({required this.date, required this.steps, this.goal = 10000});

  ⟦bool get reached => steps >= goal;⟧
  ⟦double get km => steps * 0.0007;⟧
}

方法還是 getter？沒有參數、只是「讀一個算出來的值」用 getter（reached、km）；要傳參數或會做比較多事情的用方法。

卡住了？看這裡

The expression doesn't evaluate to a function, so it can't be invoked.
