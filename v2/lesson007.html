% 和 ~/：秒數換算

新增 lesson007.dart。3725 秒是幾小時幾分幾秒？~/ 取商、% 取餘數，跟 C 的整數 / 和 % 一樣。

void main() {
  ⟦final totalSec = 3725;⟧
  ⟦final h = totalSec ~/ 3600;⟧
  ⟦final m = totalSec % 3600 ~/ 60;⟧
  ⟦final s = totalSec % 60;⟧
  ⟦print('$h 小時 $m 分 $s 秒');⟧
}

算算看：3725 % 3600 = 125，125 ~/ 60 = 2，所以是 2 分。% 和 ~/ 優先順序相同，從左算到右。

卡住了？看這裡

習慣 C 寫成 int m = totalSec / 60; 會出錯，因為 Dart 的 / 一定得到小數：

A value of type 'double' can't be assigned to a variable of type 'int'.
執行結果
$ dart run lesson007.dart
1 小時 2 分 5 秒

+=、-=、++：累加步數

一天分好幾次走路，把步數累加起來。這些寫法跟 C 完全一樣，注意變數要用 var，因為它會一直變。

void main() {
  ⟦var steps = 0;⟧
  ⟦steps += 1200;⟧ // 早上上學
  ⟦steps += 3500;⟧ // 體育課
  ⟦steps -= 200;⟧  // 扣掉誤算
  ⟦steps++;⟧       // 多走一步
  ⟦print('今天共 $steps 步');⟧
}
卡住了？看這裡

如果用 final 宣告，就不能再 += 了：

The final variable 'steps' can only be set once.
執行結果
$ dart run lesson007.dart

比較運算子：得到 true 或 false

>=、==、!= 的結果是 bool，可以存進變數、也可以直接印出來。

Dart 的字串用 == 比的是內容，不像 C 的字元陣列要用 strcmp。

void main() {
  ⟦final steps = 8234;⟧
  ⟦const goal = 10000;⟧
  ⟦final reached = steps >= goal;⟧
  ⟦print('達標了嗎？$reached');⟧
  ⟦final name = '小明';⟧
  ⟦print(name == '小明');⟧
  ⟦print(steps != goal);⟧
}
卡住了？看這裡

想比較卻少打一個 =，寫成 name = '小華' 就變成「指定」。name 是 final，Dart 會擋下來：

The final variable 'name' can only be set once.
執行結果
$ dart run lesson007.dart

true

&&、||、!：完成達標判斷

  1. 把步驟 1 的換算放回來，分和秒用 padLeft(2, '0') 補成兩位。
  2. 步數和運動時間各判斷一次。
  3. 用 && 、 || 、 ! 組合條件。
void main() {
  final totalSec = 3725;
  final steps = 8234;
  const goal = 10000;
  ⟦const minSec = 1800;⟧ // 至少運動 30 分鐘

  final h = totalSec ~/ 3600;
  final m = totalSec % 3600 ~/ 60;
  final s = totalSec % 60;
  ⟦final mm = m.toString().padLeft(2, '0');⟧
  ⟦final ss = s.toString().padLeft(2, '0');⟧

  ⟦final stepOk = steps >= goal;⟧
  ⟦final timeOk = totalSec >= minSec;⟧

  ⟦print('運動時間：$h:$mm:$ss');⟧
  ⟦print('步數達標：$stepOk');⟧
  ⟦print('時間達標：$timeOk');⟧
  ⟦print('兩個都達標：${stepOk && timeOk}');⟧
  ⟦print('至少一個：${stepOk || timeOk}');⟧
  ⟦print('步數還不夠：${!stepOk}');⟧
}
卡住了？看這裡

數學課寫 1000 < steps < 20000，在 C 不會報錯但結果是錯的；Dart 直接擋下來，要寫成 1000 < steps && steps < 20000：

The operator '<' isn't defined for the type 'bool'.
