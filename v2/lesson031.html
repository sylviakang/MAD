拆出 MyApp：第一個 StatelessWidget

  1. 寫一個 class MyApp，extends StatelessWidget。
  2. 建構子固定寫 const MyApp({super.key});，照抄就好。
  3. 覆寫 build，把原本的 MaterialApp 搬進來 return。
  4. main 只剩一行 runApp(MyApp());。

自己的 Widget 也能傳參數

  1. 寫 Greeting，欄位 final String name;，建構子用命名參數。
  2. build 裡用字串插值顯示名字。
  3. HomePage 裡寫 Greeting(name: '小明')，就跟用 Text 一樣。
import 'package:flutter/material.dart';

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(home: HomePage());
  }
}

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Color(0xFFDDF5F2),
      appBar: AppBar(title: Text('MoveGo')),
      body: Center(
        ⟦child: Greeting(name: '小明'),⟧
      ),
    );
  }
}
