用索引取出一天

索引從 0 開始，跟 C 一樣：星期一是 steps[0]，星期三是 steps[2]。再做一個存星期名稱的 List，兩個 List 用同一個索引就能對起來。

void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
⟦  final days = ['一', '二', '三', '四', '五', '六', '日'];⟧
  ⟦print('星期${days[0]}：${steps[0]} 步');⟧
  ⟦print('星期${days[2]}：${steps[2]} 步');⟧
}
卡住了？看這裡

用 steps[7] 拿第 8 天，Dart 會在執行時當掉（C 不會報錯，只會讀到亂碼）：

RangeError (length): Invalid value: Not in inclusive range 0..6: 7
執行結果
$ dart run lesson013.dart
星期一：6500 步
星期三：7300 步
3

改掉其中一天、first 和 last

  • steps[2] = 7800;：改掉星期三的值。
  • steps.first、steps.last：第一個和最後一個，不用自己算索引。
void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  ⟦steps[2] = 7800;⟧
  ⟦print(steps);⟧
  ⟦print('第一天 ${steps.first}，最後一天 ${steps.last}');⟧
}

咦，final 還能改？final 的意思是「steps 這個名字一直指向同一個 List」，不能換成另一個 List；但 List 裡面的值可以改。就像你的座位不能換，但抽屜裡的東西可以換。

卡住了？看這裡

List 裡都是整數，就不能放字串進去：

A value of type 'String' can't be assigned to a variable of type 'int'.
執行結果
$ dart run lesson013.dart
[6500, 8200, 7800, 10500, 9100, 12000, 4300]
第一天 6500，最後一天 4300

完成：星期三的步數卡

  1. 用變數 i 代表要看哪一天，改 i 就能換一天。
  2. 拿出那一天的步數，用 if 判斷有沒有達標。
  3. 沒達標就算出還差幾步。
void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  final days = ['一', '二', '三', '四', '五', '六', '日'];
  const goal = 10000;
  steps[2] = 7800;

  ⟦final i = 2;⟧
  ⟦final today = steps[i];⟧
  ⟦print('===== 星期${days[i]} =====');⟧
  ⟦print('步數：$today 步');⟧
  ⟦if (today >= goal) {⟧
  ⟦  print('已達標！');⟧
  ⟦} else {⟧
  ⟦  print('還差 ${goal - today} 步');⟧
  ⟦}⟧
}

試試看：把 i 改成 3 或 5，看看哪幾天有達標。

執行結果
$ dart run lesson013.dart
===== 星期三 =====
步數：7800 步
還差 2200 步
