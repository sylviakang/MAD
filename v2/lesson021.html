完成：步數小字典

  1. 用兩個 List 建出小字典。
  2. 另一個 Map 記「日期 → 星期幾（數字）」，再用 weekName 對照成中文。
  3. 寫 lookup 查詢，查不到的日期印「沒有紀錄」。
void main() {
  final dates = ['11/10', '11/11', '11/12', '11/13', '11/14'];
  final steps = [6500, 8200, 7300, 10500, 9100];
  final book = <String, int>{};
  for (var i = 0; i < dates.length; i++) {
    book[dates[i]] = steps[i];
  }
  ⟦final weekday = {'11/10': 1, '11/11': 2, '11/12': 3, '11/13': 4, '11/14': 5};⟧
  ⟦final weekName = {1: '一', 2: '二', 3: '三', 4: '四', 5: '五', 6: '六', 7: '日'};⟧

  ⟦print('===== 步數小字典（共 ${book.length} 天）=====');⟧
  ⟦for (final d in ['11/12', '11/13', '11/20']) {⟧
  ⟦  final w = weekName[weekday[d] ?? 0] ?? '?';⟧
  ⟦  print('${lookup(book, d)}（星期$w）');⟧
  ⟦}⟧
}

⟦String lookup(Map<String, int> data, String date) {
  final s = data[date];
  if (s == null) {
    return '$date：沒有紀錄';
  }
  return '$date：$s 步';
}⟧

單元 7 完成！weekName[weekday[d] ?? 0] 是「先查日期是星期幾，再查中文名稱」，兩層查詢。查不到的日期會變成 0，0 在 weekName 裡也查不到，最後印出「?」。
