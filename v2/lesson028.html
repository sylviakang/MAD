建立多個物件

每呼叫一次建構子，就建立一個新的物件。不用寫 new（寫了也可以，但 Dart 習慣不寫）。欄位是 final，建立之後就不能改。

void main() {
  ⟦final a = StepRecord('11/10', 6500);⟧
  ⟦final b = StepRecord('11/11', 8200);⟧
  ⟦final c = StepRecord('11/12', 7300);⟧
  ⟦print('${a.date}：${a.steps}');⟧
  ⟦print('${b.date}：${b.steps}');⟧
  ⟦print('${c.date}：${c.steps}');⟧
}

class StepRecord {
  final String date;
  final int steps;

  StepRecord(this.date, this.steps);
}

'steps' can't be used as a setter because it's final.

完成：覆寫 toString，直接 print

直接 print(a) 只會印出「Instance of 'StepRecord'」。在類別裡寫 toString() 告訴 Dart 要怎麼把這個物件變成文字，前面加 @override 表示「我要改掉原本的版本」。

void main() {
  ⟦final a = StepRecord('11/10', 6500);⟧
  ⟦final b = StepRecord('11/11', 8200);⟧
  ⟦final c = StepRecord('11/12', 7300);⟧
  ⟦print(a);⟧
  ⟦print(b);⟧
  ⟦print(c);⟧
}

class StepRecord {
  final String date;
  final int steps;

  StepRecord(this.date, this.steps);

  double kcal() => steps * 0.04;
  double km() => steps * 0.0007;

  ⟦@override⟧
  ⟦String toString() =>⟧
  ⟦    '$date ${steps.toString().padLeft(6)} 步 ${kcal().toStringAsFixed(1)} 大卡';⟧
}
