5 分鐘
  • Flutter 程式從 void main() 開始，跟 C 一樣。
  • 字串用單引號 '…'，每行用 ; 結束。

整數和小數

把 main 裡面改成下面這樣。宣告的寫法跟 C 完全一樣：型別、名字、等號、值、分號。

void main() {
  ⟦int age = 16;⟧
  ⟦double height = 172.8;⟧
  ⟦print(age);⟧
  ⟦print(height);⟧
}
卡住了？看這裡

int 放小數會出錯，例如 int x = 7.5;。要放小數就用 double。

A value of type 'double' can't be assigned to a variable of type 'int'.
執行結果

字串和布林，把資料印漂亮

  1. 加上 String 和 bool 兩個變數。
  2. 用 + 把標籤和值接起來。
  3. 數字、布林不能直接跟字串相加，要先 .toString() 變成字串。
void main() {
  ⟦String name = '小明';⟧
  int age = 16;
  double height = 172.8;
  ⟦bool isPlayer = true;⟧
  ⟦print('姓名：' + name);⟧
  ⟦print('年齡：' + age.toString());⟧
  ⟦print('身高：' + height.toString());⟧
  ⟦print('是否為選手：' + isPlayer.toString());⟧
}
卡住了？看這裡

寫成 '年齡：' + age 會出錯。C# 會幫你自動轉成字串，Dart 不會。

The argument type 'int' can't be assigned to the parameter type 'String'.

string 小寫會出錯。C# 是小寫 string，Dart 是大寫 String。

Undefined class 'string'.
執行結果
$ dart run lesson004.dart
姓名：小明
年齡：16
身高：172.8
是否為選手：true

四則運算：先猜再執行

新增檔案 calc.dart 打入下面的程式。執行前先在紙上寫下你猜的 6 個答案，再執行對對看。

void main() {
  ⟦int a = 7;⟧
  ⟦int b = 2;⟧
  ⟦print(a + b);⟧
  ⟦print(a - b);⟧
  ⟦print(a * b);⟧
  ⟦print(a / b);⟧
  ⟦print(a ~/ b);⟧
  ⟦print(a % b);⟧
}

猜錯第 4 個了嗎？在 C/C# 裡 7 / 2 是 3，在 Dart 裡 / 一定算出小數，所以是 3.5。想要整數的商要用 ~/（波浪號加斜線）。

卡住了？看這裡

int x = 7 / 2; 會出錯，因為 7 / 2 是 double。改成 int x = 7 ~/ 2; 或 double x = 7 / 2;
