新增：給一個新的 key

新增 lesson020.dart。從空的 Map 開始：<String, int>{}，角括號裡是「key 的型別, value 的型別」。

void main() {
  ⟦final book = <String, int>{};⟧
  ⟦book['11/10'] = 6500;⟧
  ⟦book['11/11'] = 8200;⟧
  ⟦print(book);⟧
}
卡住了？看這裡

角括號裡的型別寫錯了：value 寫成 String，卻放進整數：

A value of type 'int' can't be assigned to a variable of type 'String'.
執行結果
$ dart run lesson020.dart
{11/10: 6500, 11/11: 8200}
2

修改：給一個已經有的 key

寫法跟新增一樣。11/10 已經有了，所以這次是把 6500 改成 7000，Map 還是 2 筆。

void main() {
  final book = <String, int>{};
  book['11/10'] = 6500;
  book['11/11'] = 8200;
  ⟦book['11/10'] = 7000;⟧
  ⟦print(book);⟧
  ⟦print('還是 ${book.length} 筆');⟧
}
執行結果
$ dart run lesson020.dart
{11/10: 7000, 11/11: 8200}
還是 2 筆
3

刪除與累加

  • remove(key)：刪掉那一筆。
  • 累加：先用 ?? 0 拿出舊值（沒有就是 0），加上新的，再存回去。這個寫法新日期和舊日期都適用。
void main() {
  final book = <String, int>{};
  book['11/10'] = 7000;
  book['11/11'] = 8200;
  ⟦book.remove('11/11');⟧
  ⟦print('刪掉 11/11：$book');⟧
  ⟦book['11/10'] = (book['11/10'] ?? 0) + 1500;⟧
  ⟦book['11/12'] = (book['11/12'] ?? 0) + 3000;⟧
  ⟦print('累加後：$book');⟧
}
卡住了？看這裡

寫成 book['11/10'] += 1500; 會出錯，因為拿出來的值可能是 null：

The method '+' can't be unconditionally invoked because the receiver can be 'null'.
執行結果
$ dart run lesson020.dart
刪掉 11/11：{11/10: 7000}
累加後：{11/10: 8500, 11/12: 3000}
4

完成：步數小帳本

  1. 把累加寫成函式 addSteps(book, date, n)，Map 傳進函式裡修改，外面的 book 也會變。
  2. 一天記好幾次，看它自動加起來。
  3. 最後印出總共記了幾天。
void main() {
  ⟦final book = <String, int>{};⟧
  ⟦addSteps(book, '11/10', 3000);⟧
  ⟦addSteps(book, '11/10', 3500);⟧
  ⟦addSteps(book, '11/11', 8200);⟧
  ⟦addSteps(book, '11/12', 2000);⟧
  ⟦addSteps(book, '11/12', 5300);⟧
  ⟦print('===== 步數小帳本 =====');⟧
  ⟦print(book);⟧
  ⟦print('共記了 ${book.length} 天');⟧
}

⟦void addSteps(Map<String, int> book, String date, int n) {⟧
⟦  book[date] = (book[date] ?? 0) + n;⟧
⟦  print('記錄 $date +$n → ${book[date]}');⟧
⟦}⟧

試試看：在最後加一行 book.remove('11/11');，再印一次，筆數會變成 2。
