記住是哪一天：記索引

只知道 12000 還不夠，要知道是星期幾。改成記「擂主的索引」best，比較時用 steps[best]。這裡要用有索引的 for。

void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  final days = ['一', '二', '三', '四', '五', '六', '日'];
  ⟦var best = 0;⟧
  ⟦for (var i = 1; i < steps.length; i++) {⟧
  ⟦  if (steps[i] > steps[best]) {⟧
  ⟦    best = i;⟧
  ⟦  }⟧
  ⟦}⟧
  ⟦print('最佳：星期${days[best]}，${steps[best]} 步');⟧

為什麼 i 從 1 開始？索引 0 已經是擂主了，不用跟自己比。從 0 開始也不會錯，只是多比一次。

indexOf 和 contains

  • s.indexOf(10500)：回傳 10500 第一次出現的索引；找不到回傳 -1。
  • s.contains(8000)：有沒有 8000，回傳 true 或 false。
void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  final days = ['一', '二', '三', '四', '五', '六', '日'];

  ⟦print('10500 步是星期${days[i]}');⟧
  ⟦print('有沒有剛好 8000 步？${steps.contains(8000)}');⟧
  ⟦print('找 9999 的索引：${steps.indexOf(9999)}');⟧
}

indexOf 找不到時是 -1，拿 -1 當索引會當掉。用之前要先檢查 i != -1：

完成：最佳與最差的一天

  1. 把找最大、最小的索引寫成 maxIndex、minIndex 兩個函式。
  2. 印出最佳和最差的一天，以及相差幾步。
  3. 用 contains 檢查這週有沒有哪天剛好 10000 步。
void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  final days = ['一', '二', '三', '四', '五', '六', '日'];
  ⟦final hi = maxIndex(steps);⟧
  ⟦final lo = minIndex(steps);⟧
  ⟦print('最佳：星期${days[hi]}，${steps[hi]} 步');⟧
  ⟦print('最差：星期${days[lo]}，${steps[lo]} 步');⟧
  ⟦print('相差：${steps[hi] - steps[lo]} 步');⟧
  ⟦final exact = steps.contains(10000) ? '有' : '沒有';⟧
  ⟦print('剛好 10000 步的日子：$exact');⟧
}

⟦int maxIndex(List<int> list) {
  var best = 0;
  for (var i = 1; i < list.length; i++) {
    if (list[i] > list[best]) {
      best = i;
    }
  }
  return best;
}⟧

⟦int minIndex(List<int> list) {
  var worst = 0;
  for (var i = 1; i < list.length; i++) {
    if (list[i] < list[worst]) {
      worst = i;
    }
  }
  return worst;
}⟧
