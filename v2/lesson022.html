對照表

C++ 的 for (auto& [k, v] : m) 和 C# 的 foreach (var kv in m) 都是一次拿一對。Dart 用 m.entries，每一對有 .key 和 .value。

要做的事C / C++C#Dart / Flutter
走訪所有 keyfor (auto& p : m) p.first // C++foreach (var k in m.Keys)for (final k in m.keys)
走訪所有 valuefor (auto& p : m) p.secondforeach (var v in m.Values)for (final v in m.values)
一次拿一對★for (auto& [k, v] : m) // C++17foreach (var kv in m)for (final e in m.entries)
拿 key 和 value★p.first、p.secondkv.Key、kv.Valuee.key、e.value
順序★std::map 依 key 排序不保證照放進去的順序

★ 黃底＝跟 C/C# 不一樣、最容易寫錯的地方。

entries：一次拿一對

要同時印日期和步數，用 book.entries。每一圈的 e 有兩個欄位：e.key 和 e.value。

void main() {
  final book = {
    '11/10': 6500,
    '11/11': 8200,
    '11/12': 7300,
    '11/13': 10500,
    '11/14': 9100,
  };
  ⟦for (final e in book.entries) {⟧
  ⟦  final s = e.value.toString().padLeft(6);⟧
  ⟦  print('${e.key} $s 步');⟧
  ⟦}⟧
}
卡住了？看這裡

直接 for-in 走 Map 本身（少了 .entries），Dart 不知道你要走 key 還是 value：

The type 'Map<String, int>' used in the 'for' loop must implement 'Iterable'.

完成：步數帳本報表

  1. 用 entries 印出每一天，加上長條。
  2. 邊走邊打擂台，記住步數最多的日期。
  3. 最後印出總步數和最佳日期。
void main() {
  final book = {
    '11/10': 6500,
    '11/11': 8200,
    '11/12': 7300,
    '11/13': 10500,
    '11/14': 9100,
  };
  ⟦var total = 0;⟧
  ⟦var bestDate = '';⟧
  ⟦var bestSteps = 0;⟧
  ⟦print('===== 步數帳本 =====');⟧
  for (final e in book.entries) {
    final s = e.value.toString().padLeft(6);
    ⟦final bar = '■' * (e.value ~/ 1000);⟧
    print('${e.key} $s ⟦$bar⟧');
    ⟦total += e.value;⟧
    ⟦if (e.value > bestSteps) {⟧
    ⟦  bestSteps = e.value;⟧
    ⟦  bestDate = e.key;⟧
    ⟦}⟧
  }
  ⟦print('總步數：$total');⟧
  ⟦print('最佳：$bestDate（$bestSteps 步）');⟧
}

這裡擂主從 0 開始可以嗎？步數不可能是負的，所以從 0 開始沒問題。如果是氣溫這種可能是負數的資料，就要從第一筆開始。
