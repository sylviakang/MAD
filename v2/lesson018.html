先複製再排序

排序後星期一到星期日的順序就亂了，days 對不起來。所以要先複製一份：[...steps] 的意思是「把 steps 裡的東西全部倒進一個新的 List」。

void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  ⟦final sorted = [...steps];⟧
  ⟦sorted.sort();⟧
  ⟦print('排序後：$sorted');⟧
  ⟦print('原本的：$steps');⟧
}
卡住了？看這裡

由大到小：比較函式

sort((a, b) => b - a) 括號裡是一個沒有名字的箭頭函式，Dart 會一直拿兩個數 a、b 問它：

  • 回傳負數：a 排前面
  • 回傳正數：b 排前面

b - a 就是「大的排前面」，跟 C 的 qsort 比較函式一樣。

void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  final sorted = [...steps];
  ⟦sorted.sort((a, b) => b - a);⟧
  ⟦print('由大到小：$sorted');⟧
  ⟦print('前三名：${sorted.sublist(0, 3)}');⟧
}

sublist(0, 3)：從索引 0 取到索引 3 之前，也就是前 3 個。跟 C 的迴圈 i = 0; i < 3 是同一個範圍。

完成：一週步數統計器

  1. 沿用前兩堂的 sumOf、averageOf、countAtLeast、maxIndex、minIndex。
  2. 複製一份由大到小排序，取前三名。
  3. 把所有結果印成一張統計卡。
void main() {
  final steps = [6500, 8200, 7300, 10500, 9100, 12000, 4300];
  final days = ['一', '二', '三', '四', '五', '六', '日'];
  const goal = 10000;

  final hi = maxIndex(steps);
  final lo = minIndex(steps);
  ⟦final top = [...steps];⟧
  ⟦top.sort((a, b) => b - a);⟧

  print('====== 一週步數統計器 ======');
  print('總步數：${sumOf(steps)}');
  print('平均　：${averageOf(steps).toStringAsFixed(1)}');
  print('最佳　：星期${days[hi]} ${steps[hi]}');
  print('最差　：星期${days[lo]} ${steps[lo]}');
  print('達標　：${countAtLeast(steps, goal: goal)} 天');
  ⟦print('前三名：${top.sublist(0, 3)}');⟧
  ⟦print('原始資料沒有被改：$steps');⟧
}

int sumOf(List<int> list) {
  var total = 0;
  for (final x in list) {
    total += x;
  }
  return total;
}

double averageOf(List<int> list) {
  if (list.isEmpty) {
    return 0;
  }
  return sumOf(list) / list.length;
}

int countAtLeast(List<int> list, {required int goal}) {
  var count = 0;
  for (final x in list) {
    if (x >= goal) {
      count++;
    }
  }
  return count;
}

int maxIndex(List<int> list) {
  var best = 0;
  for (var i = 1; i < list.length; i++) {
    if (list[i] > list[best]) {
      best = i;
    }
  }
  return best;
}

int minIndex(List<int> list) {
  var worst = 0;
  for (var i = 1; i < list.length; i++) {
    if (list[i] < list[worst]) {
      worst = i;
    }
  }
  return worst;
}
