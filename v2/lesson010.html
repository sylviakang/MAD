把一整行接起來再印

  1. 迴圈外面準備一個空字串 var line = '';。
  2. 每一圈用 += 把一個算式接上去。
  3. 迴圈結束後才 print，所以只會印一行。
void main() {
  ⟦var line = '';⟧
  for (var i = 1; i <= 9; i++) {
    ⟦line += '2x$i=${2 * i} ';⟧
  }
  ⟦print(line);⟧
}
卡住了？看這裡

把 print(line) 寫進迴圈裡面，會印出 9 行，而且一行比一行長。print 要放在迴圈的右大括號後面。

兩層迴圈：九九乘法表

  1. 外層 a 從 1 到 9，負責「第幾行」。
  2. 每一行開始時把 line 清空。
  3. 內層 b 從 1 到 9，把 a x b 接上去，答案用 padLeft(2) 對齊。
void main() {
  ⟦for (var a = 1; a <= 9; a++) {⟧
    var line = '';
    for (var b = 1; b <= 9; b++) {
      ⟦final ans = (a * b).toString().padLeft(2);⟧
      ⟦line += '${a}x$b=$ans ';⟧
    }
    print(line);
  ⟦}⟧
}

為什麼寫 ${a}x？如果寫成 $ax，Dart 會去找一個叫 ax 的變數。用大括號 ${a} 把變數名字圍起來，就不會黏在一起。
