Map：用日期查步數

List 用 0、1、2 這種索引找資料，但「11 月 12 日走了幾步？」要先算出是第幾個才能查。Map 讓你直接用「11/12」這種名字當鑰匙（key）去查值（value），就像查字典一樣。

今天的成果

把五天的步數存成「日期 → 步數」的 Map，輸入日期就能查出步數，查不到的日期也不會出錯。

查不到會得到 null

查一個不存在的日期，Dart 不會當掉，而是給你 null（什麼都沒有）。null 不能拿來計算，最簡單的處理是 ?? 0：「如果是 null，就用 0 代替」。

void main() {
  final steps = {
    '11/10': 6500,
    '11/11': 8200,
    '11/12': 7300,
    '11/13': 10500,
    '11/14': 9100,
  };
  ⟦print(steps['12/25']);⟧
  ⟦final xmas = steps['12/25'] ?? 0;⟧
  ⟦print('12/25 走了 $xmas 步');⟧
  ⟦print('11/10 加 500 是 ${(steps['11/10'] ?? 0) + 500}');⟧
}

先記住用法就好：?? 和 null 的完整說明在單元 9。現在只要知道「從 Map 拿出來的值可能是 null，要用 ?? 給一個預設值才能計算」。

卡住了？看這裡

直接拿 Map 的值來加，Dart 會提醒你它可能是 null：

The operator '+' can't be unconditionally invoked because the receiver can be 'null'.

完成：日期查詢小工具

  1. 寫函式 lookup(data, date)：先取出值，如果是 null 就回傳「沒有紀錄」。
  2. 在 if 判斷過不是 null 之後，s 就能當一般整數使用。
  3. 用一個 List 放要查的日期，for-in 逐一查詢。
void main() {
  final steps = {
    '11/10': 6500,
    '11/11': 8200,
    '11/12': 7300,
    '11/13': 10500,
    '11/14': 9100,
  };
  ⟦final ask = ['11/12', '11/14', '11/20'];⟧
  ⟦for (final d in ask) {⟧
  ⟦  print(lookup(steps, d));⟧
  ⟦}⟧
}

⟦String lookup(Map<String, int> data, String date) {
  final s = data[date];
  if (s == null) {
    return '$date：沒有紀錄';
  }
  return '$date：$s 步';
}⟧
執行結果
