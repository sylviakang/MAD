對照表

Column 有兩個方向：「主軸」是它排東西的方向（直的），「交叉軸」是另一個方向（橫的）。記住這兩個詞，下一堂的 Row 剛好相反。

要做的事C / C++C#Dart / Flutter
由上往下排Column(children: [a, b, c])
直的方向怎麼排★mainAxisAlignment: MainAxisAlignment.center
橫的方向怎麼對齊★crossAxisAlignment: CrossAxisAlignment.start
只佔需要的高度mainAxisSize: MainAxisSize.min
中間留空SizedBox(height: 12)

★ 黃底＝跟 C/C# 不一樣、最容易寫錯的地方。

mainAxisAlignment：直的方向

Column 的主軸是直的。MainAxisAlignment.center 讓三行字在整個畫面上下置中。其他常用值：start（上）、end（下）、spaceEvenly（平均分散）。每一個都換換看。

import 'package:flutter/material.dart';

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(home: HomePage());
  }
}

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Color(0xFFF4F7FB),
      appBar: AppBar(title: Text('Column')),
      body: Column(
        ⟦mainAxisAlignment: MainAxisAlignment.center,⟧
        children: [
          Text('今日步數', style: TextStyle(fontSize: 20)),
          Text('8234', style: TextStyle(fontSize: 48)),
          Text('目標 10000 步', style: TextStyle(fontSize: 16)),
        ],
      ),
    );
  }
}

為什麼還是靠左？因為「上下」是主軸，「左右」是交叉軸，要用下一步的 crossAxisAlignment 控制。

crossAxisAlignment：橫的方向

為了看清楚橫向對齊，把字換成三條不同長度的彩色長條（Container）。Column 預設是 center；改成 CrossAxisAlignment.start 全部靠左，end 全部靠右，stretch 全部拉到跟畫面一樣寬。

import 'package:flutter/material.dart';

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(home: HomePage());
  }
}

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Color(0xFFF4F7FB),
      appBar: AppBar(title: Text('Column')),
      body: Column(
        mainAxisAlignment: MainAxisAlignment.center,
        ⟦crossAxisAlignment: CrossAxisAlignment.start,⟧
        children: [
          ⟦Container(width: 120, height: 40, color: Color(0xFF00A396)),⟧
          ⟦Container(width: 260, height: 40, color: Color(0xFF2F8CEB)),⟧
          ⟦Container(width: 190, height: 40, color: Color(0xFFFF8A3D)),⟧
        ],
      ),
    );
  }
}
