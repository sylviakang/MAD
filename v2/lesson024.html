建立：Map 的 value 是 List

新增 lesson024.dart。每個日期對到一個 List，裡面是那天每一趟的步數。

void main() {
⟦  final book = <String, List<int>>{
    '11/10': [3000, 2500, 1000],
    '11/11': [8200],
    '11/12': [2000, 5300],
  };⟧
  ⟦print(book);⟧
  ⟦print('11/10 走了 ${book['11/10']?.length} 趟');⟧
}

?. 是什麼？book['11/10'] 可能是 null，?.length 的意思是「不是 null 才取 length，是 null 就直接得到 null」。單元 9 會詳細講，這裡先認得就好。

每天的合計：沿用 sumOf

走訪 entries，每一天的 e.value 就是一個 List，直接丟給第 16 堂寫過的 sumOf。

void main() {
  final book = <String, List<int>>{
    '11/10': [3000, 2500, 1000],
    '11/11': [8200],
    '11/12': [2000, 5300],
  };
  ⟦for (final e in book.entries) {⟧
  ⟦  print('${e.key}：${sumOf(e.value)} 步');⟧
  ⟦}⟧
}

⟦int sumOf(List<int> list) {
  var total = 0;
  for (final x in list) {
    total += x;
  }
  return total;
}⟧

新增一筆：addRecord

  1. 先拿出那天的清單，沒有的話 ?? <int>[] 給一個新的空清單。
  2. add 進去。
  3. 再存回 Map（如果是新清單，這一步才會把它放進去）。
void main() {
  final book = <String, List<int>>{
    '11/10': [3000, 2500, 1000],
    '11/11': [8200],
    '11/12': [2000, 5300],
  };
  ⟦addRecord(book, '11/11', 1500);⟧
  ⟦addRecord(book, '11/13', 4000);⟧
  ⟦print(book);⟧
}

⟦void addRecord(Map<String, List<int>> book, String date, int n) {
  final list = book[date] ?? <int>[];
  list.add(n);
  book[date] = list;
}⟧

完成：每天記多筆的步數簿

  1. 新增幾筆紀錄。
  2. 走訪每一天，印出筆數、合計和每一趟的明細。
  3. 最後印出全部的總步數。
void main() {
  final book = <String, List<int>>{
    '11/10': [3000, 2500, 1000],
    '11/11': [8200],
    '11/12': [2000, 5300],
  };
  addRecord(book, '11/11', 1500);
  addRecord(book, '11/13', 4000);
  addRecord(book, '11/13', 6200);

  ⟦var grand = 0;⟧
  ⟦print('======= 步數簿 =======');⟧
  ⟦for (final e in book.entries) {⟧
  ⟦  final total = sumOf(e.value);⟧
  ⟦  grand += total;⟧
  ⟦  print('${e.key}　${e.value.length} 趟　合計 $total 步');⟧
  ⟦  for (final s in e.value) {⟧
  ⟦    print('　　・$s');⟧
  ⟦  }⟧
  ⟦}⟧
  ⟦print('全部合計：$grand 步');⟧
}

int sumOf(List<int> list) {
  var total = 0;
  for (final x in list) {
    total += x;
  }
  return total;
}

void addRecord(Map<String, List<int>> book, String date, int n) {
  final list = book[date] ?? <int>[];
  list.add(n);
  book[date] = list;
}
