null：「沒有值」也是一種值

上一個單元查 Map 時遇過 null，也先背了 ?? 0 的寫法。今天正式認識它：在 Dart 裡，一般的 int 永遠不會是 null；只有型別後面加了問號的 int? 才可以是 null。這個規定讓很多 C 裡常見的當機在寫程式時就被抓出來。

int? 不能直接計算

int? 可能是 null，null 不能加減乘除，所以 Dart 不讓你直接拿它來算。試著把下面這段打進去，看分析器怎麼說。

void main() {
  ⟦show(6500);⟧
}

⟦void show(int? today) {⟧
⟦  print(today);⟧
⟦  // print(today + 500);  // 拿掉 // 會出錯⟧
⟦}⟧

咦，傳進來的明明是 6500？Dart 看的是「型別」：參數 today 是 int?，別人也可以呼叫 show(null)。所以只要是 int?，Dart 就要求你先檢查。下一步就來檢查。

卡住了？看這裡

拿掉 // 之後的錯誤：

The operator '+' can't be unconditionally invoked because the receiver can be 'null'.

用 if 檢查：檢查完就變成 int

寫 if (today != null) 之後，在大括號裡 Dart 知道 today 一定不是 null，它就自動變成一般的 int，可以直接計算。這叫做「型別提升」。

void main() {
  ⟦show(6500);⟧
  ⟦show(null);⟧
}

⟦void show(int? today) {⟧
⟦  if (today != null) {⟧
⟦    print('今天 $today 步，再走 500 步就是 ${today + 500}');⟧
⟦  } else {⟧
⟦    print('今天還沒有紀錄');⟧
⟦  }⟧
⟦}⟧
執行結果
$ dart run lesson025.dart
今天 6500 步，再走 500 步就是 7000
今天還沒有紀錄

完成：回傳 int? 的查詢函式

  1. 函式 findSteps 查得到就回傳步數，查不到回傳 null，所以回傳型別是 int?。
  2. 呼叫的人拿到結果，先檢查再用。
  3. 只把有查到的加進總和。
void main() {
  final book = {'11/10': 6500, '11/11': 8200, '11/12': 7300};
  ⟦final ask = ['11/10', '11/15', '11/12'];⟧
  ⟦var total = 0;⟧
  ⟦for (final d in ask) {⟧
  ⟦  final s = findSteps(book, d);⟧
  ⟦  if (s != null) {⟧
  ⟦    total += s;⟧
  ⟦    print('$d：$s 步');⟧
  ⟦  } else {⟧
  ⟦    print('$d：查無紀錄，不列入計算');⟧
  ⟦  }⟧
  ⟦}⟧
  ⟦print('查到的合計：$total 步');⟧
}

⟦int? findSteps(Map<String, int> book, String date) {⟧
⟦  return book[date];⟧
⟦}⟧

回傳型別寫 int 會怎樣？book[date] 是 int?，不能當 int 回傳，Dart 會報錯。「可能沒有結果」的函式，回傳型別就加問號，讓呼叫的人知道要檢查。
