五個重點概念

講解 25 分鐘

Compose 用 Kotlin 函式畫畫面，不用 XML 拉介面。先把這五件事弄懂，今天的實作就只是照著組合。

1

@Composable 函式就是畫面

加上 @Composable 的函式負責「畫出」一塊畫面。函式名稱用大寫開頭，像類別一樣。畫面要換資料時，Compose 會重新呼叫它，這叫重組（recomposition）。

@Composable
fun Hello(name: String) {
    Text("Hello $name")
}

// 在 setContent 裡呼叫它
setContent {
    Hello("GyroQuiz")
}
2

Column、Row、Box

Column 由上往下排，Row 由左往右排，Box 疊在一起。horizontalAlignment 控制水平置中，verticalArrangement 控制垂直分布。

Column(
    modifier = Modifier.fillMaxSize(),
    horizontalAlignment = Alignment.CenterHorizontally,
    verticalArrangement = Arrangement.Center
) {
    Text("上")
    Text("下")
}
3

Modifier 串起來用

大小、間距、背景、點擊都寫在 Modifier，用點號一個接一個。順序有差：先 padding 再 background，背景就不包含間距。

Modifier
    .fillMaxWidth()      // 寬度撐滿
    .padding(16.dp)      // 外距
    .size(160.dp)        // 固定大小
// 長度用 dp，字體大小用 sp
4

Text、Image、Button

三個最常用的元件。圖片放 res/drawable，用 painterResource(R.drawable.檔名) 取得。Button 的文字寫在大括號裡。

Text("Gyro Quiz", fontSize = 40.sp, fontWeight = FontWeight.Bold)
Image(
    painter = painterResource(R.drawable.logo),
    contentDescription = "Logo"
)
Button(onClick = { /* 按下要做的事 */ }) {
    Text("新遊戲")
}
5

把事件交給呼叫的人

HomeScreen 不知道「新遊戲」要去哪一頁，所以把按下去的動作當參數傳進來。型別 () -> Unit 就是 C# 的 Action。第 4 堂換頁時就是靠這個。

@Composable
fun HomeScreen(onNewGame: () -> Unit, onRecords: () -> Unit) {
    Button(onClick = onNewGame) { Text("新遊戲") }
}

// 先傳空的動作，讓畫面能跑
HomeScreen(onNewGame = {}, onRecords = {})

01

建立專案

題本規定：Package name 與 App 名稱
一般 -1 / -1

02

確認 App 名稱與鎖定直向

避免轉向時答題狀態不見

打開 app/src/main/AndroidManifest.xml，確認 application 的 label 指向 @string/app_name，再到 activity 加上 screenOrientation。手機一轉向畫面就會重建，鎖直向可以避免答到一半資料不見。

AndroidManifest.xml（只改 activity 這段）
<activity
    android:name=".MainActivity"
    android:exported="true"
    android:screenOrientation="portrait"
    android:theme="@style/Theme.Q00">

再打開 res/values/strings.xml 確認 app_name 是 Q00。

完成後Android Studio 可能在 screenOrientation 那行顯示黃色提示，比賽用的是手機模擬器，可以忽略。

05

寫出首頁 HomeScreen

首頁 UI 四個元素
首頁 UI 2

在 gyroquiz00 套件上按右鍵 → New → Kotlin Class/File → File，命名 HomeScreen。輸入下面的程式，紅字的 import 用 Alt + Enter 自動補上。

HomeScreen.kt
@Composable
fun HomeScreen(onNewGame: () -> Unit, onRecords: () -> Unit) {
    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        Image(
            painter = painterResource(R.drawable.logo),
            contentDescription = "Logo",
            modifier = Modifier.size(160.dp)
        )
        Spacer(Modifier.height(16.dp))
        Text("Gyro Quiz", fontSize = 40.sp, fontWeight = FontWeight.Bold)
        Spacer(Modifier.height(48.dp))
        Button(onClick = onNewGame, modifier = Modifier.width(220.dp)) {
            Text("新遊戲", fontSize = 20.sp)
        }
        Spacer(Modifier.height(16.dp))
        OutlinedButton(onClick = onRecords, modifier = Modifier.width(220.dp)) {
            Text("遊玩紀錄", fontSize = 20.sp)
        }
    }
}
06

讓 MainActivity 顯示首頁

App 一打開就是首頁

把範本產生的 Greeting 相關程式刪掉，setContent 裡改成呼叫 HomeScreen。主題函式的名稱是依專案名稱產生的，Name 填 Q00 就叫 Q00Theme。

MainActivity.kt
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            Q00Theme {
                Surface(Modifier.fillMaxSize().safeDrawingPadding()) {
                    HomeScreen(onNewGame = {}, onRecords = {})
                }
            }
        }
    }
}

safeDrawingPadding() 讓畫面避開狀態列與瀏海，不然標題會被蓋住。

完成後按綠色三角形 Run，模擬器出現 Logo、Gyro Quiz 標題與兩個按鈕，App 名稱是 Q00。
07

加上 Preview 不用每次開模擬器

加快調整畫面的速度

在 HomeScreen.kt 最下面加一個預覽函式，右上角切到 Split 就能直接看到畫面。改字型大小或間距時，用預覽比重新執行快很多。

HomeScreen.kt
@Preview(showBackground = true)
@Composable
fun HomePreview() {
    HomeScreen(onNewGame = {}, onRecords = {})
}
完成後右側 Preview 視窗顯示首頁。
