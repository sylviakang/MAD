講解 20 分鐘

1

限制在範圍內

游標的「中心」最多只能走到距離邊緣一個半徑的地方，整顆球才會留在範圍內。所以下限是 left + r、上限是 right - r。

fun clamp(value: Float, min: Float, max: Float): Float =
    if (value < min) min else if (value > max) max else value

val x = clamp(rawX, left + CURSOR_RADIUS, right - CURSOR_RADIUS)
2

基準角度＝相對座標

游標位置不是看「目前角度」，而是看「目前角度 − 校正時的角度」。一開始基準是 0；雙擊時把基準設成目前角度，相減變 0，游標自然回到中心。之後再傾斜，就是相對於這個姿勢的變化。

x = 中心 + (angleY - baseY) × 靈敏度

雙擊：baseY = angleY   →   angleY - baseY = 0   →   x = 中心
3

偵測雙擊

pointerInput 搭配 detectTapGestures，可以分別處理單擊、雙擊、長按。放在最外層 Box，整個畫面任何地方雙擊都有效。

Modifier.pointerInput(Unit) {
    detectTapGestures(onDoubleTap = {
        baseX = angleX
        baseY = angleY
    })
}
4

為什麼不直接把角度歸零

把 angleX 設回 0 也能讓游標回中心，但題本要求「重新矯正陀螺儀的計算」。保留原始角度、另外記基準，之後如果要顯示總傾斜角或重新校正都不會亂，評審看程式也一眼看得出是相對座標。
