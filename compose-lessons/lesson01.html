1

val 與 var

能用 val 就用 val，只有真的會變的值才用 var。型別通常讓 Kotlin 自己推斷，要寫的話放在名稱後面、用冒號隔開。

fun variables() {
    var score = 0               // 型別推斷為 Int
    val total = 10              // 之後不能改
    val title: String = "GyroQuiz"
    score += 3
    println("$title：$score / $total 題")
    // GyroQuiz：3 / 10 題
    println(7 / 2)    // 3
    println(7 / 2.0)  // 3.5
    println(7 % 2)    // 1
}
2

數字與轉型

Kotlin 不會自動把 Int 變成 Double，C# 的 (double)x 要改成 x.toDouble()。計時用毫秒時數字很大，記得用 Long。

fun numbers() {
    val sec: Int = 731
    val ms: Long = sec * 1000L
    val ratio: Float = 3 / 10f
    println(ms)                       // 731000
    println(ratio)                    // 0.3
    println(sec.toDouble() / 60)      // 12.183333333333334
    println("42".toInt() + 1)         // 43
    println("abc".toIntOrNull())      // null
    println(3.7.toInt())              // 3（直接捨去）
}
3

字串模板與格式

C# 的 $"{x}" 在 Kotlin 是 "$x"，有運算時加大括號 ${ }。補零用 padStart，題本要求的時間格式全靠它。

fun strings() {
    val q = 3
    val total = 10
    println("第 $q 題，共 $total 題，進度 ${q * 100 / total}%")
    // 第 3 題，共 10 題，進度 30%
    println("5".padStart(2, '0'))     // 05
    println("%.2f".format(3.14159))   // 3.14
    println("%02d:%02d".format(1, 5)) // 01:05
    val name = "Gyro"
    println(name.length)              // 4
    println(name.uppercase())         // GYRO
}
4

if 是運算式

Kotlin 沒有 ? : 三元運算子，因為 if 本身就能回傳值。注意 if 當運算式時一定要有 else。

fun ifExpr() {
    val correct = 7
    val passText = if (correct >= 6) "及格" else "不及格"
    println(passText)   // 及格
    val bigger = if (3 > 5) 3 else 5
    println(bigger)     // 5
}
5

when 取代 switch

不用寫 break，一個分支可以放多個值或一段範圍。when 也能直接回傳值，回傳時要有 else。

fun grade(correct: Int): String = when (correct) {
    10 -> "滿分"
    in 7..9 -> "很棒"
    in 4..6 -> "再加油"
    else -> "多練習"
}
// grade(10) → 滿分   grade(8) → 很棒   grade(2) → 多練習

fun optionName(key: String): String = when (key) {
    "a", "A" -> "第 1 個選項"
    "b", "B" -> "第 2 個選項"
    else -> "其他"
}
// optionName("B") → 第 2 個選項

// 沒有括號的 when，就是一串 if / else if
val h = when {
    hour == 0 -> 12
    hour > 12 -> hour - 12
    else -> hour
}
6

迴圈與區間

1..3 包含 3，0 until 3 不含 3。C# 的 for (int i = 0; i < n; i++) 幾乎都寫成 0 until n。

fun loops() {
    for (i in 1..3) print("$i ")           // 1 2 3
    println()
    for (i in 0 until 3) print("$i ")      // 0 1 2
    println()
    for (i in 10 downTo 0 step 5) print("$i ")  // 10 5 0
    println()
    repeat(3) { print("★") }              // ★★★
    println()
    var n = 3
    while (n > 0) { print("$n "); n-- }    // 3 2 1
}
