錯誤題數與答對題數

題本說「曾經答錯題數，該題答錯幾次都只算一題」，所以用 Set 記 qid。答錯後還要繼續答到對才能換題，因此每題最後都會答對；答對題數定義成「一次就答對」的題數 = 總題數 − 錯誤題數。

val wrongIds = remember { mutableSetOf<String>() }
// 答錯時
wrongIds.add(q.qid)
// 結束時
val wrong = wrongIds.size
val correct = questions.size - wrong

3

Locale.US 很重要

模擬器語言是中文時，a 會變成「下午」，格式就錯了，直接失分。指定 Locale.US 才會固定是 AM/PM。hh 是 12 小時制，HH 是 24 小時制。

SimpleDateFormat("yyyy.MM.dd hh:mm a", Locale.US)
    .format(Date(millis))      // 2026.06.26 05:45 PM

SimpleDateFormat("yyyy.MM.dd hh:mm a")  // 中文環境：2026.06.26 05:45 下午
4

SQLiteOpenHelper

繼承它要寫兩個函式：onCreate 在資料庫第一次建立時建表；onUpgrade 在版本號變大時執行。之後用 writableDatabase 寫、readableDatabase 讀。

class RecordDb(context: Context) :
    SQLiteOpenHelper(context, "gyroquiz.db", null, 1) {
    override fun onCreate(db: SQLiteDatabase) {
        db.execSQL("CREATE TABLE records (…)")
    }
    override fun onUpgrade(db: SQLiteDatabase, oldVersion: Int, newVersion: Int) {
        db.execSQL("DROP TABLE IF EXISTS records")
        onCreate(db)
    }
}

ContentValues 新增資料

ContentValues 就是「欄位名稱 → 值」的對照表，不用自己拼 SQL 字串，也不怕引號出錯。

6

改了資料表要清資料

onCreate 只會在第一次執行。如果改了 CREATE TABLE 的欄位，舊的資料庫還在，就會出錯。練習時直接在模擬器長按 App → 應用程式資訊 → 儲存空間 → 清除資料，或解除安裝重裝。

需將答題結果保存至 SQLite
SQLite 8

新增 RecordDb.kt。end_time 存毫秒（INTEGER），排序與格式化都方便。

RecordDb.kt
class RecordDb(context: Context) : SQLiteOpenHelper(context, "gyroquiz.db", null, 1) {

    override fun onCreate(db: SQLiteDatabase) {
        db.execSQL(
            "CREATE TABLE records (" +
                "id INTEGER PRIMARY KEY AUTOINCREMENT, " +
                "correct INTEGER, wrong INTEGER, duration INTEGER, end_time INTEGER)"
        )
    }

    override fun onUpgrade(db: SQLiteDatabase, oldVersion: Int, newVersion: Int) {
        db.execSQL("DROP TABLE IF EXISTS records")
        onCreate(db)
    }

    fun insert(r: GameResult) {
        val values = ContentValues()
        values.put("correct", r.correct)
        values.put("wrong", r.wrong)
        values.put("duration", r.durationSec)
        values.put("end_time", r.endMillis)
        writableDatabase.insert("records", null, values)
    }
}

App.kt
@Composable
fun GyroQuizApp() {
    val context = LocalContext.current
    val allQuestions = remember { loadQuestions(context) }
    val db = remember { RecordDb(context) }
    var screen by remember { mutableStateOf(Screen.HOME) }
    var result by remember { mutableStateOf<GameResult?>(null) }

    Surface(modifier = Modifier.fillMaxSize().safeDrawingPadding()) {
        when (screen) {
            Screen.HOME -> HomeScreen(
                onNewGame = { screen = Screen.QUIZ },
                onRecords = { screen = Screen.RECORDS }
            )
            Screen.QUIZ -> QuizScreen(
                allQuestions = allQuestions,
                onExit = { screen = Screen.HOME },
                onFinish = { r ->
                    db.insert(r)
                    result = r
                    screen = Screen.RESULT
                }
            )
            Screen.RESULT -> ResultScreen(
                result = result,
                onPlayAgain = { screen = Screen.QUIZ },
                onHome = { screen = Screen.HOME }
            )
            Screen.RECORDS -> RecordsScreen(onBack = { screen = Screen.HOME })
        }
    }
}
