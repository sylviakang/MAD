講解 25 分鐘

1

碰撞判斷：點在不在矩形裡

游標中心的 x 在 left～right 之間、y 在 top～bottom 之間，就是在這個選項上。四個都不在（例如在選項間的縫隙）回傳 -1。

fun hitIndex(x: Float, y: Float, rects: List<FloatArray>): Int {
    for (i in rects.indices) {
        val r = rects[i]
        if (x >= r[0] && x <= r[2] && y >= r[1] && y <= r[3]) return i
    }
    return -1
}
2

key 變了就從 0 開始

把 hovered 當成 LaunchedEffect 的 key：移到別的選項，hovered 改變，舊的計時被取消、新的從 0 開始。這就是「移動至其他選項需重新計算進度」。index 也放進 key，換題時一定重新開始。

LaunchedEffect(hovered, index) {
    dwell = 0f
    if (hovered < 0) return@LaunchedEffect
    val start = System.currentTimeMillis()
    while (dwell < 1f) {
        delay(16)
        dwell = dwellProgress(System.currentTimeMillis() - start)
    }
    choose(hovered)
}
3

drawArc 畫圓形進度條

drawArc 的角度從 3 點鐘方向開始算，-90f 代表從 12 點鐘開始。掃過的角度 360f × 進度，useCenter = false 加上 Stroke 就是一圈弧線。

drawArc(
    color = Color(0xFF1565C0),
    startAngle = -90f,
    sweepAngle = 360f * dwell,
    useCenter = false,
    topLeft = Offset(c.x - r, c.y - r),
    size = Size(r * 2, r * 2),
    style = Stroke(8f)
)
4

16 毫秒更新一次

螢幕每秒約更新 60 次，每次約 16 毫秒。delay(16) 讓進度條看起來是連續的，又不會浪費效能。

QuizLogic.kt
// 游標中心落在哪一個選項的範圍內，都不在就回傳 -1
// rects 每一項是 floatArrayOf(left, top, right, bottom)
fun hitIndex(x: Float, y: Float, rects: List<FloatArray>): Int {
    for (i in rects.indices) {
        val r = rects[i]
        if (x >= r[0] && x <= r[2] && y >= r[1] && y <= r[3]) return i
    }
    return -1
}

// 停留進度 0～1，3000 毫秒到 1
fun dwellProgress(elapsedMs: Long, totalMs: Long = 3000): Float =
    clamp(elapsedMs.toFloat() / totalMs, 0f, 1f)
HitTest.kt
class HitTest {
    private val rects = listOf(
        floatArrayOf(0f, 0f, 100f, 100f), floatArrayOf(110f, 0f, 210f, 100f),
        floatArrayOf(0f, 110f, 100f, 210f), floatArrayOf(110f, 110f, 210f, 210f)
    )

    @Test
    fun hit() {
        assertEquals(0, hitIndex(50f, 50f, rects))
        assertEquals(3, hitIndex(200f, 200f, rects))
        assertEquals(-1, hitIndex(105f, 50f, rects))   // 落在兩格中間的縫
    }

    @Test
    fun dwell() {
        assertEquals(0f, dwellProgress(0), 0.0001f)
        assertEquals(0.5f, dwellProgress(1500), 0.0001f)
        assertEquals(1f, dwellProgress(4000), 0.0001f)
        assertEquals(0.2f, dwellProgress(1000, 5000), 0.0001f)
    }
}
