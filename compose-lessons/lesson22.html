1

遊戲迴圈：每一幀算一次

GyroQuiz 的游標直接由感測器數值算出來；但「會滾的球」有速度，要每一幀依經過時間更新位置。withFrameNanos 會在畫面每次要重畫時呼叫，給你現在的奈秒時間。

LaunchedEffect(Unit) {
    var last = 0L
    while (true) {
        withFrameNanos { now ->
            if (last != 0L) {
                val dt = min((now - last) / 1_000_000_000f, 0.05f)
                // 速度 += 加速度 × dt；位置 += 速度 × dt
            }
            last = now
        }
    }
}
2

文字地圖

地圖用字串清單表示，一個字元一格。題本給的地圖直接複製成 listOf(…)，畫的時候兩層 for 迴圈，每格依字元畫不同顏色。位置用「格」當單位，畫的時候才乘上每格像素。

val LAB = listOf(
    "########",
    "#......#",
    "#.##...#",
    "########"
)
val cell = min(size.width / LAB[0].length, size.height / LAB.size)
3

分軸碰撞

先只移動 x，撞牆就退回並把 vx 歸零；再只移動 y。這樣球貼著牆時還能沿著牆滑，不會整顆卡住。dt 上限 0.05 秒、速度有上限，避免一幀移動太多直接穿牆。

var x = pos.x + vx * dt
if (hits(LAB, x, pos.y)) { x = pos.x; vx = 0f }
var y = pos.y + vy * dt
if (hits(LAB, x, y)) { y = pos.y; vy = 0f }

分軸碰撞

球不能穿牆，貼牆可以滑
GridLab.kt
fun isWall(grid: List<String>, c: Int, r: Int): Boolean =
    r < 0 || c < 0 || r >= grid.size || c >= grid[0].length || grid[r][c] == '#'

// 球（半徑 r 格）看成正方形，蓋到的格子有牆就算撞到
fun hits(grid: List<String>, x: Float, y: Float, r: Float = 0.3f): Boolean {
    val e = 0.001f
    for (row in floor(y - r + e).toInt()..floor(y + r - e).toInt())
        for (col in floor(x - r + e).toInt()..floor(x + r - e).toInt())
            if (isWall(grid, col, row)) return true
    return false
}
GridLab.kt
    // 遊戲迴圈：每一幀拿到現在時間（奈秒），算出 dt 再移動
    LaunchedEffect(Unit) {
        var last = 0L
        while (true) {
            withFrameNanos { now ->
                if (last != 0L) {
                    val dt = min((now - last) / 1_000_000_000f, 0.05f)
                    var vx = (vel.x - ax * 1.5f * dt) * 0.98f
                    var vy = (vel.y + ay * 1.5f * dt) * 0.98f
                    // x、y 分開走，撞牆的那一軸退回並停下
                    var x = pos.x + vx * dt
                    if (hits(LAB, x, pos.y)) { x = pos.x; vx = 0f }
                    var y = pos.y + vy * dt
                    if (hits(LAB, x, y)) { y = pos.y; vy = 0f }
                    pos = Offset(x, y)
                    vel = Offset(vx, vy)
                }
                last = now
            }
        }
    }
完成後球碰到牆停下；斜著傾斜時會沿著牆滑動，不會卡住。
