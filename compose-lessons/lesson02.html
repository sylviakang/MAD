1

null safety

型別後面加 ? 才能放 null。用 ?. 跳過、用 ?: 給預設值，就不會因為 null 閃退。!! 等於「我保證不是 null」，猜錯就閃退，比賽時不要用。

fun findTitle(ok: Boolean): String? = if (ok) "GyroQuiz" else null

fun nullSafety() {
    var best: Int? = null
    println(best ?: 0)                   // 0
    val title: String? = findTitle(false)
    println(title?.length)               // null
    println(title?.length ?: 0)          // 0
    best = 9
    if (best != null) println(best + 1)  // 10（檢查過就能直接用）
    println("12".toIntOrNull() ?: -1)    // 12
    println("ab".toIntOrNull() ?: -1)    // -1
}
2

預設與具名參數

參數可以給預設值，呼叫時用名稱指定某一個參數。Compose 的元件全都這樣呼叫，例如 Text(text = "…", fontSize = 20.sp)，第 3 堂起天天用。

fun label(text: String, prefix: String = "Q", width: Int = 4): String =
    prefix + text.padStart(width, '0')

// label("7")                    → Q0007
// label("12", prefix = "No.")   → No.0012
// label(width = 2, text = "5")  → Q05（具名時順序可以換）
3

class 與 data class

建構子直接寫在類別名稱後面。data class 自動幫你做好 toString、== 比內容、copy，存資料的類別都用它。

data class Option(val key: String, val text: String)

val o1 = Option("a", "onCreate()")
val o2 = Option("a", "onCreate()")
println(o1)                          // Option(key=a, text=onCreate())
println(o1 == o2)                    // true
println(o1.copy(text = "onStart()")) // Option(key=a, text=onStart())

class Counter(val total: Int) {
    var current = 1
        private set                  // 外面只能讀，不能改
    val isLast: Boolean
        get() = current == total     // 每次讀都重新計算
    fun next() { if (current < total) current++ }
}
// Counter(3) 呼叫兩次 next() 後：current = 3，isLast = true

5

List、Set、Map

listOf 建好就不能改，要加東西用 mutableListOf。Set 不會重複，add 重複的值會回傳 false，題本的「答錯幾次都只算一題」用它最快。

val keys = listOf("a", "b", "c", "d")
println(keys.size)           // 4
println(keys[2])             // c
println(keys.indexOf("c"))   // 2

val picked = mutableListOf<String>()
picked.add("0003")
picked.add("0007")
println(picked)              // [0003, 0007]

val wrong = mutableSetOf<String>()
println(wrong.add("0003"))   // true
println(wrong.add("0003"))   // false（已經有了）
println(wrong.size)          // 1

val colors = mapOf("a" to "紅", "b" to "藍")
println(colors["a"])         // 紅
println(colors["z"] ?: "無") // 無（查不到是 null）
6

lambda 與集合函式

C# 的 LINQ 在 Kotlin 是集合函式，大括號就是 lambda，只有一個參數時用 it 代表。shuffled().take(10) 就是題本要的「隨機 10 題不重複」。

val scores = listOf(8, 10, 6, 10, 3)
println(scores.filter { it >= 8 })    // [8, 10, 10]
println(scores.map { it * 10 })       // [80, 100, 60, 100, 30]
println(scores.count { it == 10 })    // 2
println(scores.any { it < 5 })        // true
println(scores.sortedDescending())    // [10, 10, 8, 6, 3]
println(scores.maxOrNull())           // 10（空清單時是 null）
println(scores.joinToString(" / "))   // 8 / 10 / 6 / 10 / 3
scores.forEachIndexed { i, s ->
    if (i < 2) println("第 ${i + 1} 局：$s")
}                                     // 第 1 局：8 和 第 2 局：10
println((1..10).toList().shuffled().take(3))  // 例如 [2, 5, 1]，每次不同
