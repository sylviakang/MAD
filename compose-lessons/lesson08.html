1

rawQuery 與 Cursor

rawQuery 回傳 Cursor，一開始指在第一筆之前。moveToNext() 移到下一筆，沒有資料時回傳 false。欄位用 SELECT 的順序取，0 是第一個。

val c = readableDatabase.rawQuery(
    "SELECT correct, wrong, duration, end_time FROM records ORDER BY end_time DESC", null
)
while (c.moveToNext()) {
    list.add(GameResult(c.getInt(0), c.getInt(1), c.getInt(2), c.getLong(3)))
}
c.close()
2

排序交給 SQL

ORDER BY end_time DESC 讓最新的在最上面。end_time 存毫秒數字，排序就是數字大小，不會有字串排序的問題。

3

LazyColumn

只畫出螢幕看得到的項目，資料再多也不會卡。items(list) 會對每一筆呼叫一次大括號。注意 items 要 import androidx.compose.foundation.lazy.items。

LazyColumn(Modifier.fillMaxSize()) {
    items(records) { r ->
        Text("答對 ${r.correct} / 錯誤 ${r.wrong}")
    }
}

RecordsScreen.kt
@Composable
fun RecordsScreen(records: List<GameResult>, onBack: () -> Unit) {
    BackHandler { onBack() }
    Column(Modifier.fillMaxSize()) {
        BackBar(title = "遊玩紀錄", onBack = onBack)
        if (records.isEmpty()) {
            Text("尚無紀錄", modifier = Modifier.padding(24.dp), fontSize = 18.sp)
        }
        LazyColumn(Modifier.fillMaxSize()) {
            items(records) { r ->
                Card(Modifier.fillMaxWidth().padding(horizontal = 16.dp, vertical = 6.dp)) {
                    Column(Modifier.padding(16.dp)) {
                        Text("答對 ${r.correct} / 錯誤 ${r.wrong}", fontSize = 20.sp)
                        Text("答題時長：${formatDuration(r.durationSec)}")
                        Text("結束時間：${formatEndTime(r.endMillis)}")
                    }
                }
            }
        }
    }
}
