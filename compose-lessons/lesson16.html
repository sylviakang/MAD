四個重點概念

講解 20 分鐘

Compose 的動畫都是「目標值改變，畫面自己補中間的過程」。你只要改狀態，不用自己寫計時器。

1

animate…AsState：數值慢慢變過去

把原本直接用的數值包一層，目標值一改，回傳值會在 300 毫秒內慢慢變到新值。Float、Color、Int、Dp 都有對應的版本。

val progress by animateFloatAsState(
    targetValue = (index + 1) / questions.size.toFloat(),
    label = "progress"
)
2

AnimatedVisibility：出現與消失

visible 從 false 變 true 時播放 enter 動畫，變回 false 時播放 exit 動畫。用 + 可以組合兩種效果。

AnimatedVisibility(
    visible = phase == Phase.WRONG,
    enter = fadeIn() + slideInVertically(),
    exit = fadeOut()
) { Text("選擇錯誤") }
3

Crossfade：換頁淡入淡出

把 when (screen) 包進 Crossfade。注意大括號裡要用參數 s，不能再用 screen，否則淡出中的舊頁面會變成新頁面。

Crossfade(targetState = screen, label = "screen") { s ->
    when (s) { … }
}
4

tween：自訂時間長度

預設動畫約 300 毫秒。想要更慢或更快就傳 animationSpec = tween(毫秒)。

val shown by animateIntAsState(
    targetValue = if (started) result.correct else 0,
    animationSpec = tween(800),
    label = "correct"
)

04

選項邊框有過場

停留中淡灰框、答錯紅框、答對綠框

把第 12 堂的 borderColor 與 then 換成下面的寫法。每個選項都一直有邊框，只是沒選時是透明的，所以不再需要 then：

QuizScreen.kt（選項 Box）
                            // 紅框、綠框、停留中的淡灰框，顏色切換有過場
                            val borderColor by animateColorAsState(
                                targetValue = when {
                                    marked == i && phase == Phase.WRONG -> Color.Red
                                    marked == i -> Color(0xFF2E7D32)
                                    hovered == i && phase == Phase.PLAYING -> Color(0x66000000)
                                    else -> Color.Transparent
                                },
                                label = "border"
                            )
                            Box(
                                modifier = Modifier
                                    .weight(1f)
                                    .fillMaxSize()
                                    .background(OptionPalette[colors[i]], RoundedCornerShape(16.dp))
                                    .border(if (marked == i) 6.dp else 3.dp, borderColor, RoundedCornerShape(16.dp))
完成後游標停在選項上，邊框淡淡出現；選錯時邊框變紅、選對時變綠。
05

結算數字跳動

答對題數從 0 跳到結果

started 一開始是 false，畫面出現後 LaunchedEffect 把它改成 true，目標值從 0 變成答對題數，動畫就開始：

ResultScreen.kt
    // 數字從 0 跳到結果：started 由 false 變 true 時開始動畫
    var started by remember { mutableStateOf(false) }
    LaunchedEffect(Unit) { started = true }
    val shownCorrect by animateIntAsState(
        targetValue = if (started) result?.correct ?: 0 else 0,
        animationSpec = tween(800),
        label = "correct"
    )
ResultScreen.kt（原本的 Text）
Text("答對題數：$shownCorrect", fontSize = 24.sp)
06

主題顏色

整個 App 換主色，按鈕、進度條一起變

New Project 範本已經有 ui/theme/Theme.kt。找到 LightColorScheme，改 primary 與 secondary。範本產生的主題函式名稱跟 App 名稱有關，App 名稱 Q00 時叫 Q00Theme，MainActivity 的 setContent 裡要用它包住 GyroQuizApp：

ui/theme/Theme.kt
private val LightColorScheme = lightColorScheme(
    primary = Color(0xFF1565C0),
    secondary = Color(0xFF00897B),
    tertiary = Color(0xFFF9A825)
)

同一個檔案的 Q00Theme 參數 dynamicColor 預設是 true，Android 12 以上會改用桌布顏色。想固定顏色就把預設值改成 false。

完成後按鈕和進度條都換成藍色。
