用 Logcat 找閃退位置

15 分鐘

App 一閃退，馬上看 Logcat，不要猜。

  1. 下方工具列打開 Logcat，上方篩選選自己的 App（package:mine）。
  2. 搜尋框輸入 FATAL，找到 FATAL EXCEPTION: main。
  3. 下一行是例外種類，例如 IndexOutOfBoundsException、FileNotFoundException。
  4. 往下找第一行 at tw.mad08.gyroquiz00…，點藍色的檔名與行號就會跳到出錯的那一行。
  5. 畫面不對但沒閃退時，在程式裡加 Log.d("GQ", "index=$index")，在 Logcat 搜尋 GQ 觀察數值。

抓錯 8 題

60 分鐘

每題先讀症狀，在自己的專案重現一次，再修正。修好並在模擬器確認後才勾選。

01

按了沒反應

點「下一題」題號一直是 1/10。
有問題的程式
@Composable
fun Demo() {
    var index = 0
    Button(onClick = { index++ }) { Text("${index + 1}/10") }
}

寫下你的修正後再點開

index 不是狀態。改成 var index by remember { mutableIntStateOf(0) }。

02

時間變成「下午」

模擬器語言是中文時，結束時間顯示 2026.06.26 05:45 下午。
有問題的程式
fun formatEndTime(millis: Long): String =
    SimpleDateFormat("yyyy.MM.dd hh:mm a").format(Date(millis))

寫下你的修正後再點開

缺少 Locale.US。

03

進度條不動

前 9 題進度條都是空的，最後一題才突然滿格。
有問題的程式
LinearProgressIndicator(
    progress = { ((index + 1) / questions.size).toFloat() }
)

寫下你的修正後再點開

整數除法先算成 0 才轉 Float。要先轉 Float 再除：(index + 1) / questions.size.toFloat()。

04

最後一題閃退

第 10 題答對時 App 閃退，Logcat 顯示 IndexOutOfBoundsException。
有問題的程式
fun choose(i: Int) {
    if (i != q.answerIndex) return
    index++
    if (index == questions.size) onFinish(result)
}

寫下你的修正後再點開

index++ 後畫面會用 questions[10] 重組。要先判斷是不是最後一題，不是才 index++。

05

一進答題頁就閃退

Logcat 顯示 FileNotFoundException: questions.json。
有問題的程式
val text = context.assets.open("questions.json")
    .bufferedReader().use { it.readText() }

寫下你的修正後再點開

檔名大小寫不符，assets 裡是 Questions.json。

06

存檔時閃退

加了一個新欄位 category 之後，結算時閃退，訊息是 no such column。
有問題的程式
override fun onCreate(db: SQLiteDatabase) {
    db.execSQL("CREATE TABLE records (id INTEGER PRIMARY KEY AUTOINCREMENT, correct INTEGER, category TEXT, …)")
}

寫下你的修正後再點開

模擬器裡還是舊的資料庫，onCreate 不會再執行。清除 App 資料或把版本號從 1 改成 2。

07

答題頁越來越卡

進答題頁後畫面一直重畫，游標延遲很大。
有問題的程式
.onGloballyPositioned {
    val b = it.boundsInRoot()
    rects[i] = floatArrayOf(b.left, b.top, b.right, b.bottom)
}

寫下你的修正後再點開

每次排版都寫入一個新陣列，狀態一直改變、一直重畫。加上 contentEquals 判斷，相同就不寫。

08

換選項進度不歸零

游標從 A 移到 B，進度條接著 A 的進度繼續跑。
有問題的程式
LaunchedEffect(Unit) {
    val start = System.currentTimeMillis()
    while (true) { … }
}

寫下你的修正後再點開

key 用 Unit 只會啟動一次。要把 hovered（與 index）放進 key，換選項就重新開始。
