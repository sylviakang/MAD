六個重點概念

講解 20 分鐘

Compose 最重要的觀念：畫面是狀態的結果。改狀態，畫面就跟著變。

1

remember + mutableStateOf

一般的 var 每次重組都會被重設，畫面也不知道它變了。用 mutableStateOf 包起來，Compose 才會在值改變時重畫；remember 讓值在重組之間保留下來。by 讓你直接讀寫，不用寫 .value。

@Composable
fun Counter() {
    var count by remember { mutableStateOf(0) }
    Button(onClick = { count++ }) {
        Text("按了 $count 次")
    }
}
2

錯誤示範：一般變數

這段按了不會變。count 每次重組都從 0 開始，而且改它不會觸發重畫。看到「按了沒反應」，第一個檢查是不是忘了 mutableStateOf。

@Composable
fun BrokenCounter() {
    var count = 0                     // 錯：不是狀態
    Button(onClick = { count++ }) {
        Text("按了 $count 次")         // 永遠是 0
    }
}
3

用列舉決定顯示哪一頁

把「目前在哪一頁」存成狀態，再用 when 決定呼叫哪個畫面函式。改 screen 就等於換頁。這就是不用 Navigation 套件的換頁方式。

enum class Screen { HOME, QUIZ, RESULT, RECORDS }

var screen by remember { mutableStateOf(Screen.HOME) }
when (screen) {
    Screen.HOME -> HomeScreen(onNewGame = { screen = Screen.QUIZ }, …)
    Screen.QUIZ -> QuizScreen(…)
    …
}
4

狀態放在上層

screen 放在最上層的 GyroQuizApp，各頁只拿到「要換頁時呼叫的函式」。各頁不用知道別頁存在，改流程只要改 GyroQuizApp 一個地方。這叫狀態提升（state hoisting）。

// 子畫面只收事件
@Composable
fun RecordsScreen(onBack: () -> Unit) { … }

// 上層決定事件要做什麼
RecordsScreen(onBack = { screen = Screen.HOME })
5

BackHandler 攔截返回鍵

使用者按手機的返回鍵或手勢時，預設會直接關掉 App。在頁面裡放 BackHandler，就能改成自己的動作，例如回首頁或跳出確認框。

@Composable
fun ResultScreen(onPlayAgain: () -> Unit, onHome: () -> Unit) {
    BackHandler { onHome() }
    …
}
6

AlertDialog 用旗標控制

Compose 的對話框不是呼叫 Show()，而是「旗標為 true 時就畫出來」。按取消把旗標設回 false，對話框就消失。

var showExit by remember { mutableStateOf(false) }

if (showExit) {
    AlertDialog(
        onDismissRequest = { showExit = false },
        title = { Text("確認退出") },
        text = { Text("確定要退出答題嗎？") },
        confirmButton = { TextButton(onClick = onExit) { Text("退出") } },
        dismissButton = { TextButton(onClick = { showExit = false }) { Text("取消") } }
    )
}

App.kt
enum class Screen { HOME, QUIZ, RESULT, RECORDS }

@Composable
fun GyroQuizApp() {
    var screen by remember { mutableStateOf(Screen.HOME) }

    Surface(modifier = Modifier.fillMaxSize().safeDrawingPadding()) {
        when (screen) {
            Screen.HOME -> HomeScreen(
                onNewGame = { screen = Screen.QUIZ },
                onRecords = { screen = Screen.RECORDS }
            )
            Screen.QUIZ -> QuizScreen(
                onExit = { screen = Screen.HOME },
                onFinish = { screen = Screen.RESULT }
            )
            Screen.RESULT -> ResultScreen(
                onPlayAgain = { screen = Screen.QUIZ },
                onHome = { screen = Screen.HOME }
            )
            Screen.RECORDS -> RecordsScreen(onBack = { screen = Screen.HOME })
        }
    }
}

QuizScreen.kt
// 第 4 堂的暫時版本：只有返回 Dialog，第 5 堂換成真正的答題頁
@Composable
fun QuizScreen(onExit: () -> Unit, onFinish: () -> Unit) {
    var showExit by remember { mutableStateOf(false) }
    BackHandler { showExit = true }

    Column(Modifier.fillMaxSize()) {
        BackBar(title = "答題", onBack = { showExit = true })
        Text("答題頁（第 5 堂完成）", modifier = Modifier.padding(24.dp))
        Button(onClick = onFinish, modifier = Modifier.padding(24.dp)) {
            Text("假裝答完")
        }
    }

    if (showExit) {
        AlertDialog(
            onDismissRequest = { showExit = false },
            title = { Text("確認退出") },
            text = { Text("確定要退出答題嗎？本局不會保存。") },
            confirmButton = { TextButton(onClick = onExit) { Text("退出") } },
            dismissButton = { TextButton(onClick = { showExit = false }) { Text("取消") } }
        )
    }
}
完成後答題頁按返回會跳出確認框，按取消留下、按退出回首頁。
