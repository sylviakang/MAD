用列舉表示目前狀態

答題頁同一時間只會處於一種狀態：作答中、答錯鎖定中、答對展示中。用列舉存起來，每段程式只要問「現在是哪個狀態」。

enum class Phase { PLAYING, WRONG, CORRECT }

PLAYING ──停滿 3 秒、選錯──▶ WRONG ──5 秒後──▶ PLAYING
PLAYING ──停滿 3 秒、選對──▶ CORRECT ──2 秒後──▶ 下一題 PLAYING
                                          └─最後一題─▶ 結算頁
2

鎖定中不計算停留

停留計時多一個 key：phase。不是 PLAYING 就直接結束，所以答錯的 5 秒內停在任何選項都不會被選，但游標照樣能移動。

LaunchedEffect(hovered, phase, index) {
    dwell = 0f
    if (phase != Phase.PLAYING || hovered < 0) return@LaunchedEffect
    …
}
3

第二個 LaunchedEffect 處理狀態

另一段 LaunchedEffect 以 phase 為 key：變成 WRONG 時倒數 5 秒，變成 CORRECT 時等 2 秒換題。兩段各管各的，比全部寫在一起好除錯。

LaunchedEffect(phase, index) {
    when (phase) {
        Phase.WRONG -> { 倒數 5 秒；marked = -1；phase = PLAYING }
        Phase.CORRECT -> { delay(2000)；換題或結束 }
        Phase.PLAYING -> {}
    }
}
4

條件式 Modifier

只有被標記的選項要加邊框。用 then 接一個「條件成立才加」的 Modifier，其他選項接空的 Modifier。

.then(
    if (marked == i) Modifier.border(6.dp, borderColor, RoundedCornerShape(16.dp))
    else Modifier
)

    LaunchedEffect(hovered, phase, index) {
        dwell = 0f
        if (phase != Phase.PLAYING || hovered < 0) return@LaunchedEffect
        val start = System.currentTimeMillis()
        while (dwell < 1f) {
            delay(16)
            dwell = dwellProgress(System.currentTimeMillis() - start)
        }
        marked = hovered
        if (hovered == q.answerIndex) {
            phase = Phase.CORRECT
        } else {
            wrongIds.add(q.qid)
            Toast.makeText(context, "選擇錯誤", Toast.LENGTH_SHORT).show()
            phase = Phase.WRONG
        }
    }

處理答錯與答對

鎖定 5 秒、紅色 100～0%、綠框 2 秒後下一題、最後一題導頁
禁止 5 秒 3、100～0% 2、2 秒後下一題 1、導頁 0.5
QuizScreen.kt
    LaunchedEffect(phase, index) {
        when (phase) {
            Phase.WRONG -> {
                val start = System.currentTimeMillis()
                while (true) {
                    val passed = System.currentTimeMillis() - start
                    lock = 1f - dwellProgress(passed, 5000)
                    if (passed >= 5000) break
                    delay(16)
                }
                marked = -1
                phase = Phase.PLAYING
            }
            Phase.CORRECT -> {
                delay(2000)
                marked = -1
                if (index == questions.lastIndex) {
                    onFinish(
                        GameResult(
                            correct = questions.size - wrongIds.size,
                            wrong = wrongIds.size,
                            durationSec = (elapsedMs / 1000).toInt(),
                            endMillis = System.currentTimeMillis()
                        )
                    )
                } else {
                    colors = nextColorIndexes(OptionPalette.size, colors)
                    index++
                    phase = Phase.PLAYING
                }
            }
            Phase.PLAYING -> {}
        }
    }
