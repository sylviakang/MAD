六個重點概念

講解 30 分鐘

先用模擬器的虛擬感測器看懂軸向，再寫程式。

1

陀螺儀量的是轉速

陀螺儀回傳三個軸的角速度，單位是弧度／秒。手機靜止時三個值都接近 0，就算手機是斜的也一樣。所以「傾斜了多少」要自己算：角度 += 角速度 × 經過時間。

角速度 2 rad/s，持續 0.25 秒
→ 轉了 2 × 0.25 = 0.5 rad（約 29 度）

fun integrate(angle: Float, rate: Float, dtSec: Float) =
    angle + rate * dtSec
2

手機的三個軸

x 軸指向手機右邊，y 軸指向手機上方，z 軸垂直螢幕朝向你。往右傾（右邊往下）是繞 y 軸正轉，游標往右；上緣往前壓低是繞 x 軸負轉，游標往上。方向反了就把正負號對調。

values[0]  繞 x 軸（前後傾）→ 游標上下
values[1]  繞 y 軸（左右傾）→ 游標左右
values[2]  繞 z 軸（平面旋轉）→ 本題不用

x = 中心 + angleY × 靈敏度
y = 中心 + angleX × 靈敏度
3

timestamp 算經過時間

每個感測器事件都有 timestamp，單位是奈秒（10⁻⁹ 秒）。跟上一次相減再除以 10 億就是秒數。第一次事件沒有上一次，只記下時間。

if (lastNs != 0L) {
    val dt = (e.timestamp - lastNs) / 1_000_000_000f
    angleX = integrate(angleX, e.values[0], dt)
}
lastNs = e.timestamp

註冊感測器一樣用 DisposableEffect

跟第 6 堂的生命週期監聽同一個模式：進畫面註冊，離開畫面在 onDispose 取消，不然離開答題頁後還在耗電。SENSOR_DELAY_GAME 大約每秒 50 次，游標夠順。

DisposableEffect(Unit) {
    val sm = context.getSystemService(Context.SENSOR_SERVICE) as SensorManager
    val gyro = sm.getDefaultSensor(Sensor.TYPE_GYROSCOPE)
    val listener = object : SensorEventListener { … }
    sm.registerListener(listener, gyro, SensorManager.SENSOR_DELAY_GAME)
    onDispose { sm.unregisterListener(listener) }
}
5

量出四個選項的位置

onGloballyPositioned 會在元件排好版後告訴你它的位置。boundsInRoot() 是相對整個視窗的矩形。四個矩形最左、最上、最右、最下圍起來的範圍，中心就是游標的起點。

.onGloballyPositioned {
    val b = it.boundsInRoot()
    val r = floatArrayOf(b.left, b.top, b.right, b.bottom)
    if (rects[i]?.contentEquals(r) != true) rects[i] = r
}

01

陀螺儀換算函式與測試

先確定數學是對的

在 QuizLogic.kt 加兩個函式，再寫測試 GyroMathTest.kt。

QuizLogic.kt
// 陀螺儀：角速度 (rad/s) × 經過秒數 = 轉過的角度
fun integrate(angle: Float, rate: Float, dtSec: Float): Float = angle + rate * dtSec

// 角度換成游標位置：中心點 + (目前角度 - 校正時的角度) × 靈敏度
fun cursorPos(center: Float, angle: Float, baseAngle: Float, pxPerRad: Float): Float =
    center + (angle - baseAngle) * pxPerRad
GyroMathTest.kt
class GyroMathTest {
    @Test
    fun integrateAngle() {
        // 每秒轉 2 弧度，經過 0.25 秒，轉了 0.5 弧度
        assertEquals(0.5f, integrate(0f, 2f, 0.25f), 0.0001f)
        // 反方向轉回來
        assertEquals(0.3f, integrate(0.5f, -0.4f, 0.5f), 0.0001f)
    }

    @Test
    fun cursorFromAngle() {
        // 角度等於基準角時，游標在中心
        assertEquals(500f, cursorPos(500f, 0.3f, 0.3f, 800f), 0.01f)
        // 比基準多 0.1 弧度，移動 80 px
        assertEquals(580f, cursorPos(500f, 0.4f, 0.3f, 800f), 0.01f)
    }
}
完成後兩個測試通過。

03

註冊陀螺儀並累加角度

依陀螺儀的傾斜角度計算
移動 10 的基礎

放在計時程式下面。onAccuracyChanged 一定要覆寫，但內容可以空著。

QuizScreen.kt
    // ---------- 陀螺儀：角速度積分成角度 ----------
    var angleX by remember { mutableFloatStateOf(0f) }
    var angleY by remember { mutableFloatStateOf(0f) }
    DisposableEffect(Unit) {
        val sm = context.getSystemService(Context.SENSOR_SERVICE) as SensorManager
        val gyro = sm.getDefaultSensor(Sensor.TYPE_GYROSCOPE)
        var lastNs = 0L
        val listener = object : SensorEventListener {
            override fun onSensorChanged(e: SensorEvent) {
                if (lastNs != 0L) {
                    val dt = (e.timestamp - lastNs) / 1_000_000_000f
                    angleX = integrate(angleX, e.values[0], dt)
                    angleY = integrate(angleY, e.values[1], dt)
                }
                lastNs = e.timestamp
            }
            override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
        }
        sm.registerListener(listener, gyro, SensorManager.SENSOR_DELAY_GAME)
        onDispose { sm.unregisterListener(listener) }
    }

05

算出游標位置

游標初始在 4 個選項的中心點
中心點 2

放在陀螺儀下面：

QuizScreen.kt
    // ---------- 選項位置與游標 ----------
    val rects = remember { mutableStateListOf<FloatArray?>(null, null, null, null) }
    var originX by remember { mutableFloatStateOf(0f) }
    var originY by remember { mutableFloatStateOf(0f) }
    val ready = rects.all { it != null }
    val left = if (ready) rects.minOf { it!![0] } else 0f
    val top = if (ready) rects.minOf { it!![1] } else 0f
    val right = if (ready) rects.maxOf { it!![2] } else 0f
    val bottom = if (ready) rects.maxOf { it!![3] } else 0f
    val cursorX = cursorPos((left + right) / 2, angleY, 0f, PX_PER_RAD)
    val cursorY = cursorPos((top + bottom) / 2, angleX, 0f, PX_PER_RAD)
