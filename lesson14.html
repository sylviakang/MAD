題目的 7 個步驟

先照題目逐步寫下來，每一步一行，不要自己合併或簡化，評審就是照這個算的。

// D = 數據最大值，N = 刻度區間數（題目範例 N = 4）
// Step1  Raw  = D / N
// Step2  Mag  = 10 ^ floor(log10(Raw))
// Step3  Norm = Raw / Mag
// Step4  Norm <= 1.5 → B = 1
//        Norm <= 3   → B = 2
//        Norm <= 7   → B = 5
//        Norm >  7   → B = 10
// Step5  Tick = B × Mag
// Step6  Ymax = ceil(D / Tick) × Tick
// Step7  Y 軸 = [0, Tick, 2Tick, …, Ymax]
2

寫成程式

回傳 YAxis 物件，裡面有最大值、刻度間距，以及算好的刻度清單。沒有資料時題目沒規定，這裡畫 0～N。

YAxis niceAxis(double dMax, {int n = 4}) {
  if (dMax <= 0) return YAxis(n.toDouble(), 1);
  final raw = dMax / n;                                       // Step1
  final mag = pow(10, (log(raw) / ln10 + _eps).floor())
      .toDouble();                                             // Step2
  final norm = raw / mag;                                      // Step3
  final double b;                                              // Step4
  if (norm <= 1.5) {
    b = 1;
  } else if (norm <= 3) {
    b = 2;
  } else if (norm <= 7) {
    b = 5;
  } else {
    b = 10;
  }
  final tick = b * mag;                                        // Step5
  final max = (dMax / tick - _eps).ceil() * tick;              // Step6
  return YAxis(max, tick);
}
3

兩個小數陷阱

電腦裡的小數不是精確的。下面兩個結果都是實際執行印出來的，不處理就會在特定數字算錯。

// 陷阱 1：log10(1000) 應該是 3
log(1000) / ln10            // 2.9999999999999996
(log(1000) / ln10).floor()  // 2 ✗ → Mag 少一位
// 解法：floor 之前先 + 1e-9

// 陷阱 2：0.3 ÷ 0.1 應該是 3
(0.1 * 3) / 0.1             // 3.0000000000000004
((0.1 * 3) / 0.1).ceil()    // 4 ✗ → Y 軸多一格
// 解法：ceil 之前先 - 1e-9
4

用測試驗證

演算法最適合寫單元測試：題目範例、手算過的數字、Norm 剛好 1.5／3／7 的邊界、兩個陷阱，全部寫成 expect。

test('題目範例：Ymax 800、N 4、Tick 200', () {
  final a = niceAxis(800);
  expect(a.max, 800);
  expect(a.tick, 200);
  expect(a.ticks, [0, 200, 400, 600, 800]);
});

test('邊界：Norm 剛好 1.5、3、7', () {
  expect(niceAxis(6).tick, 1);   // 6 / 4 = 1.5 → B 1
  expect(niceAxis(12).tick, 2);  // 12 / 4 = 3 → B 2
  expect(niceAxis(28).tick, 5);  // 28 / 4 = 7 → B 5
});

接進長條圖

Y 軸用「完整的」最大值計算，動畫播放時刻度固定不動，只有長條在長。刻度的小數位數由 tick 決定。

final axis = niceAxis(kcal.fold(0.0, (a, b) => a > b ? a : b));
BarChartPainter(
  values: kcal,
  yMax: axis.max,
  tick: axis.tick,
  progress: progress,     // 動畫值
)

// tick 100 → "300"；tick 0.2 → "0.6"（不是 0.6000000000000001）
int decimalsOf(double tick) =>
    max(0, -(log(tick) / ln10 + _eps).floor());
String _num(double v) => v.toStringAsFixed(decimalsOf(tick));
