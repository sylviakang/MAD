六個重點概念

跟著教練一起做

範例取自教練版專案，已用 Flutter 3.47 通過 flutter analyze，並用 flutter test 驗證時段邊界、重開讀回、檔案壞掉三種情況。

1

資料模型 StepRecord

一筆紀錄只記兩件事：時間和步數。卡路里、里程都能從步數算出來，不要另外存。

class StepRecord {
  StepRecord({required this.time, required this.steps});

  final DateTime time;
  final int steps;

  factory StepRecord.fromJson(Map<String, dynamic> json) => StepRecord(
        time: DateTime.parse(json['time'] as String),
        steps: json['steps'] as int,
      );

  Map<String, dynamic> toJson() => {
        'time': time.toIso8601String(),
        'steps': steps,
      };
}
2

檔案長什麼樣子

整個檔案就是一個 JSON 陣列。時間用 ISO 8601 字串存，讀回來 DateTime.parse 一行就好。

[
  {"time": "2026-03-02T06:00:00.000", "steps": 100},
  {"time": "2026-03-02T06:01:00.000", "steps": 200},
  {"time": "2026-03-02T23:59:00.000", "steps": 300}
]
3

讀檔：第一次和壞掉都要顧

第一次開 App 沒有檔案；比賽中改來改去檔案也可能壞掉。兩種情況都當作沒有資料，App 不能閃退。

Future<void> load() async {
  _records.clear();
  if (!await _file.exists()) return;
  try {
    final list = jsonDecode(await _file.readAsString()) as List;
    _records.addAll(list.map((e) => StepRecord.fromJson(e)));
  } on FormatException {
    // 檔案壞掉就當作沒有資料
  }
}
4

寫檔：整份重寫

資料量小，最簡單可靠的做法是每次新增都把整份 List 重寫一次。flush: true 確保真的寫進去。

Future<void> _save() async {
  final text = jsonEncode(_records.map((r) => r.toJson()).toList());
  await _file.writeAsString(text, flush: true);
}

Future<void> add(DateTime time, int steps) async {
  if (steps <= 0) return;
  _records.add(StepRecord(time: time, steps: steps));
  await _save();
}
5

依日查詢

DateTime 用 == 比較會連時分秒一起比，所以要自己寫 isSameDay。

bool isSameDay(DateTime a, DateTime b) =>
    a.year == b.year && a.month == b.month && a.day == b.day;

int stepsOfDay(DateTime day) => _records
    .where((r) => isSameDay(r.time, day))
    .fold(0, (sum, r) => sum + r.steps);
6

四個時段的邊界

題目的時段是 00:00～06:00、06:01～12:00…，06:00 整算第一段。換成「一天中的第幾分鐘」再比較，邊界最不容易錯。

int slotOf(DateTime t) {
  final m = t.hour * 60 + t.minute;
  if (m <= 6 * 60) return 0;     // 00:00～06:00
  if (m <= 12 * 60) return 1;    // 06:01～12:00
  if (m <= 18 * 60) return 2;    // 12:01～18:00
  return 3;                      // 18:01～23:59
}
