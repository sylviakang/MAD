Achievement 類別

radial 是三個字串，int.parse 認得 0x 開頭，可以直接變成 Color。達成條件文字從 condition 算出來。

class Achievement {
  …
  final int condition;
  final String image;
  final List<Color> radial;

  String get title => '${condition ~/ 1000}K Steps';   // 10K Steps

  factory Achievement.fromJson(Map<String, dynamic> json) => Achievement(
    id: json['id'] as int,
    condition: json['condition'] as int,
    image: json['image'] as String,
    radial: [for (final s in json['radial'] as List) Color(int.parse(s))],
  );
}
3

哪一天解鎖的？

把紀錄依時間排序，一筆一筆累加，第一次超過條件的那筆紀錄就是解鎖時間。排序前先複製一份，不要動到原本的清單。

int get totalSteps => _records.fold(0, (sum, r) => sum + r.steps);

DateTime? reachedAt(int condition) {
  final sorted = [..._records]
    ..sort((a, b) => a.time.compareTo(b.time));
  var sum = 0;
  for (final r in sorted) {
    sum += r.steps;
    if (sum >= condition) return r.time;
  }
  return null;
}
4

解鎖日期要存起來

題目要求「從持久化儲存獲取解鎖日期」。第一次算出來就寫進 settings.json，之後補了更早的步數，徽章的日期也不會跟著跳。

final Map<int, DateTime> _unlocks = {};

DateTime? unlockedAt(int id, int condition) {
  if (totalSteps < condition) return null;      // 還沒解鎖
  final saved = _unlocks[id];
  if (saved != null) return saved;              // 之前存過
  final date = reachedAt(condition) ?? DateTime.now();
  _unlocks[id] = date;
  unawaited(_saveSettings());
  return date;
}

// settings.json
// {"goal":10000,"unlocks":{"1":"2026-03-02T09:00:00.000"}}

進度條與進度文字

進度條是總步數除以條件，超過 1 要 clamp。文字用 k 表示，無條件捨去到小數一位，整數就不顯示 .0。

String fmtK(int steps) {
  final tenths = steps ~/ 100;          // 6542 → 65
  final whole = tenths ~/ 10;           // 6
  final dec = tenths % 10;              // 5
  return dec == 0 ? '${whole}k' : '$whole.${dec}k';
}

LinearProgressIndicator(
  value: (total / a.condition).clamp(0.0, 1.0),
  color: AppColors.accent,
),
Text('${fmtK(total)} / ${fmtK(a.condition)}'),   // 6.5k / 10k
