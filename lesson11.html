六個重點概念

跟著教練一起做

範例取自教練版專案，已用 Flutter 3.47 通過 flutter analyze，並用 widget test 逐格檢查：第一格是 0、播到一半介於兩者之間、播完等於真正進度、點擊後回到 0。

1

AnimationController

它只做一件事：在 duration 時間內把 value 從 0 推到 1。需要 vsync，所以 State 要加上 SingleTickerProviderStateMixin。

class _HomePageState extends State<HomePage>
    with SingleTickerProviderStateMixin {
  late final AnimationController _ring = AnimationController(
    vsync: this,
    duration: const Duration(milliseconds: 1200),
  );
  …
}
2

加上速度曲線

直線速度看起來很生硬。CurvedAnimation 把 0～1 的時間換成「先快後慢」等不同節奏，value 一樣是 0 到 1。

late final Animation<double> _ringCurve = CurvedAnimation(
  parent: _ring,
  curve: Curves.easeOutCubic,
);

// 常用曲線
// Curves.linear      等速
// Curves.easeOut     先快後慢（最常見）
// Curves.easeInOut   慢快慢
// Curves.elasticOut  衝過頭再彈回
3

AnimatedBuilder 重畫

動畫每一格都會呼叫 builder。把真正的進度乘上動畫值，圓環就從 0 長到目標。只有 builder 裡的東西會重畫，其他部分不受影響。

AnimatedBuilder(
  animation: _ringCurve,
  builder: (_, _) => ProgressDial(
    steps: fmtThousands(steps),
    percent: percentOf(steps, repo.goal),
    progress: steps / repo.goal * _ringCurve.value,
    onTapPercent: _editGoal,
  ),
)
4

開頁播放、離開釋放

initState 裡 forward 就是「開啟首頁時播放」。dispose 一定要寫，否則離開頁面後動畫還在跑，Debug Console 會出現錯誤。

@override
void initState() {
  super.initState();
  _ring.forward();
}

@override
void dispose() {
  _ring.dispose();
  _scroll.dispose();
  super.dispose();
}
5

點擊重播

forward(from: 0) 會把 value 拉回 0 再播一次。同一個 GestureDetector 可以同時接點擊和長按，互不影響。

void _replay() => _ring.forward(from: 0);

GestureDetector(
  onTap: _replay,                 // 點擊重播
  onLongPress: () => Navigator.push(…StepDetectPage…),
  child: AnimatedBuilder(…),
)

// 換日期時也重播
onTap: () {
  setState(() => _selected = d);
  _replay();
},
6

Tween 和乘法一樣

Tween 是把 0～1 換成 begin～end。目標會隨日期改變時，直接在 builder 裡乘比較簡單，不用每次重建 Tween。

// 寫法一：Tween（目標固定時好用）
final anim = Tween<double>(begin: 0, end: 0.85).animate(_ringCurve);
RingPainter(progress: anim.value, …)

// 寫法二：直接乘（目標會變時好用）
RingPainter(progress: 0.85 * _ringCurve.value, …)

// 兩種在每一格算出的數字完全相同
