六組對照

左 C#・右 Dart

同一件事的兩種寫法並排。Dart 範例都已實際執行過，註解裡的值就是印出結果。

1

async 與 await

寫法幾乎相同。C# 回傳 Task，Dart 回傳 Future；Dart 的方法名稱不用加 Async 字尾。

C#
async Task<string> LoadNameAsync()
{
    await Task.Delay(1000);
    return "MoveGo";
}

string name = await LoadNameAsync();
Console.WriteLine($"載入 {name}");
Dart
Future<String> loadName() async {
  await Future.delayed(const Duration(seconds: 1));
  return 'MoveGo';
}

final name = await loadName();
print('載入 $name');  // 載入 MoveGo
2

同時等待多個工作

Task.WhenAll 對應 Future.wait，傳入的是 List，結果也是 List。

C#
int[] results = await Task.WhenAll(
    DelayedSteps(100), DelayedSteps(200), DelayedSteps(300));
Console.WriteLine(string.Join(", ", results));
Dart
final results = await Future.wait(
    [delayedSteps(100), delayedSteps(200), delayedSteps(300)]);
print(results);  // [100, 200, 300]
3

例外處理

C# 把型別寫在 catch 括號裡；Dart 用 on 指定型別，catch 只負責取得例外物件。

C#
int ToSteps(string input)
{
    try { return int.Parse(input); }
    catch (FormatException e)
    {
        Console.WriteLine($"不是數字：{e.Message}");
        return 0;
    }
    finally { Console.WriteLine("檢查完畢"); }
}
Dart
int toSteps(String input) {
  try {
    return int.parse(input);
  } on FormatException catch (e) {
    print('不是數字：${e.source}');
    return 0;
  } finally {
    print('檢查完畢');
  }
}
4

非同步資料流

IAsyncEnumerable 對應 Stream。Dart 函式要標 async*，產生資料用 yield，不寫 return。

C#
async IAsyncEnumerable<int> Ticker(int n)
{
    for (int i = 1; i <= n; i++)
    {
        await Task.Delay(100);
        yield return i;
    }
}

await foreach (var t in Ticker(3))
    Console.WriteLine($"tick {t}");
Dart
Stream<int> ticker(int n) async* {
  for (var i = 1; i <= n; i++) {
    await Future.delayed(const Duration(milliseconds: 100));
    yield i;
  }
}

await for (final t in ticker(3)) {
  print('tick $t');  // tick 1、tick 2、tick 3
}
5

JSON 與資料類別

C# 的 JsonSerializer 會自動對應屬性；Dart（Flutter）不能自動轉換，fromJson 和 toJson 要自己寫。這是比賽一定會用到的寫法。

C#
public class Achievement
{
    public int Id { get; set; }
    public int Condition { get; set; }
}

var opts = new JsonSerializerOptions { PropertyNameCaseInsensitive = true };
var list = JsonSerializer.Deserialize<List<Achievement>>(json, opts)!;
string back = JsonSerializer.Serialize(list[0]);
Dart
class Achievement {
  final int id;
  final int condition;
  Achievement(this.id, this.condition);

  factory Achievement.fromJson(Map<String, dynamic> j) =>
      Achievement(j['id'] as int, j['condition'] as int);

  Map<String, dynamic> toJson() => {'id': id, 'condition': condition};
}

final list = (jsonDecode(json) as List)
    .map((e) => Achievement.fromJson(e as Map<String, dynamic>))
    .toList();
final back = jsonEncode(list[0]);  // {"id":2,"condition":5000}
6

LINQ 進階對照

最大的差別：OrderBy 回傳新序列，sort 會直接改掉原清單。

C#
var steps = new List<int> { 800, 300, 1200, 500 };
var asc = steps.OrderBy(s => s).ToList();  // steps 不變
int total = steps.Sum();
int first = asc.First(s => s < 600);
bool all = steps.All(s => s > 0);
int count = steps.Count(s => s >= 500);
Dart
final steps = [800, 300, 1200, 500];
steps.sort();                         // steps 變成 [300, 500, 800, 1200]
final total = steps.fold<int>(0, (a, b) => a + b);  // 2800
final first = steps.firstWhere((s) => s < 600);     // 300
final all = steps.every((s) => s > 0);              // true
final count = steps.where((s) => s >= 500).length;  // 3

解析 JSON 並排序

把左邊的 C# 改寫成 Dart
C#
string json = "[{\"id\":2,\"condition\":5000},{\"id\":1,\"condition\":1000}]";
using var doc = JsonDocument.Parse(json);
var conditions = doc.RootElement.EnumerateArray()
    .Select(e => e.GetProperty("condition").GetInt32())
    .OrderBy(c => c)
    .ToList();
Console.WriteLine($"[{string.Join(", ", conditions)}]");
Dart 預期輸出
[1000, 5000]
寫完再打開：參考答案
import 'dart:convert';

void main() {
  const json = '[{"id":2,"condition":5000},{"id":1,"condition":1000}]';
  final conditions =
      (jsonDecode(json) as List).map((e) => e['condition'] as int).toList();
  conditions.sort();
  print(conditions);
}

把左邊的 C# 改寫成 Dart

    {
        await Task.Delay(200);

寫完再打開：參考答案
Stream<int> countdown(int n) async* {
  for (var i = n; i >= 1; i--) {
    await Future.delayed(const Duration(milliseconds: 200));
    yield i;
  }
}

Future<void> main() async {
  await for (final i in countdown(3)) {
    print(i);
  }
  print('開始！');
}
