1

只留年月日，往前推 8 天

DateTime.now() 帶著時分秒，先用 dateOnly 去掉。往前推用「日減 i」，DateTime 會自動處理跨月、跨年、閏年。

DateTime dateOnly(DateTime d) => DateTime(d.year, d.month, d.day);

// T, T-1, …, T-7
List<DateTime> recent8(DateTime anchor) => [
      for (var i = 0; i < 8; i++)
        DateTime(anchor.year, anchor.month, anchor.day - i),
    ];

recent8(DateTime(2026, 3, 2));
// Mar 02, Mar 01, Feb 28, Feb 27, … Feb 23
2

日期格式自己寫

題目指定 E、MMM、MMM dd、yyyy.MM.dd 四種格式，不能用 intl，就用兩個陣列查表。

const _weeks = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'];
const _months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
                 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];

String two(int n) => n.toString().padLeft(2, '0');

String fmtE(DateTime d) => _weeks[d.weekday - 1];          // Mon
String fmtMMM(DateTime d) => _months[d.month - 1];         // Mar
String fmtMMMdd(DateTime d) => '${fmtMMM(d)} ${two(d.day)}'; // Mar 02
String fmtYmd(DateTime d) =>
    '${d.year}.${two(d.month)}.${two(d.day)}';            // 2026.03.02

4

showDatePicker

回傳 Future<DateTime?>，按取消拿到 null。選完要把 T 和選取日都換掉，列表捲回最左邊。

Future<void> _pickDate() async {
  final picked = await showDatePicker(
    context: context,
    initialDate: _anchor,
    firstDate: DateTime(2020),
    lastDate: DateTime.now(),
  );
  if (picked == null) return;
  setState(() {
    _anchor = dateOnly(picked);
    _selected = _anchor;
  });
  if (_scroll.hasClients) _scroll.jumpTo(0);
}
