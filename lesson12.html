題目附的影片為了方便觀察，同一段動畫會重複播好幾次，實作時只要播一次。用可以逐格前進的播放器，記下這幾件事。

// 影片觀察表（每段動畫填一張）
// 1. 起點：從 0 開始？還是從舊的值開始？
// 2. 終點：停在真正的進度？
// 3. 時長：結束格 − 開始格，÷ 每秒格數

2

參數集中在 AnimSpec

時間和曲線散在程式各處，對照影片時會改到眼花。全部搬到一個檔案，調整時只改這裡。

class AnimSpec {
  // progress.mp4
  static const ringDuration = Duration(milliseconds: 1200);
  static const ringCurve = Curves.easeOutCubic;

  // progress_recent.mp4
  static const recentDuration = Duration(milliseconds: 1000);
  static const recentCurve = Curves.easeOut;
  static const recentStagger = 0.06; // 0 = 同時開始
  static const recentEach = 0.55;
}
3

兩個 Controller

圓環和近 8 日各自重播，所以各用一個 Controller。超過一個時，mixin 要換成 TickerProviderStateMixin。

class _HomePageState extends State<HomePage>
    with TickerProviderStateMixin {
  late final _ring = AnimationController(
      vsync: this, duration: AnimSpec.ringDuration);
  late final _recent = AnimationController(
      vsync: this, duration: AnimSpec.recentDuration);

  @override
  void initState() {
    super.initState();
    _ring.forward();
    _recent.forward();
  }
  …
}
4

Interval 錯開 8 格

8 格共用一個 Controller。第 i 格從 i × 0.06 開始，跑 0.55 的時間。Interval 會把範圍外的值自動變成 0 或 1。

static double recentAt(int i, double t) {
  final start = (i * recentStagger).clamp(0.0, 1.0);
  final end = (start + recentEach).clamp(start, 1.0);
  return recentCurve.transform(Interval(start, end).transform(t));
}

// 最後一格：7 × 0.06 + 0.55 = 0.97 ≤ 1
// 超過 1 的話，最後一格會被截掉、跑不完
5

AnimatedBuilder 包住清單

每一格的進度 = 當天步數 ÷ 目標 × 自己的動畫值。點 Item 時兩個動畫都重播。

AnimatedBuilder(
  animation: _recent,
  builder: (_, _) => ListView.separated(
    …
    itemBuilder: (_, i) {
      final d = days[i];
      return DayChip(
        progress: repo.stepsOfDay(d) / repo.goal *
            AnimSpec.recentAt(i, _recent.value),
        onTap: () {
          setState(() => _selected = d);
          _recent.forward(from: 0);
          _ring.forward(from: 0);
        },
        …
      );
    },
  ),
)
6

用數字挑曲線

從影片量出 25%、50%、75% 時間點的位置，跟各種曲線比誤差，最小的就是答案。都不像時用 Cubic 自己調四個數字。

// 量到 [0.55, 0.85, 0.96] 時的比較結果
// linear                 0.25  0.50  0.75   誤差 0.860
// easeOut                0.38  0.68  0.91   誤差 0.392
// easeOutCubic           0.60  0.88  0.98   誤差 0.090 ← 最接近
// easeOutQuart           0.70  0.91  0.99   誤差 0.240
// fastOutSlowIn          0.24  0.78  0.96   誤差 0.388

final v = Curves.easeOutCubic.transform(0.5); // 0.875
