六個重點概念

跟著教練一起做

範例取自教練版專案，已用 Flutter 3.47 通過 flutter analyze。ShakeDetector 用固定時間與 Random(56) 測試了靜止、同一高峰、冷卻時間、等於門檻和 1～3 步的範圍。

1

為什麼看合力

手機怎麼拿，三軸的數字就怎麼變。合力只看「加速度有多大」，不管方向，所以拿直的、橫的、放口袋都能用同一個門檻。

double get magnitude => sqrt(x * x + y * y + z * z);

// 上一堂在模擬器量到的大概範圍
// 平放不動     約 9.8（只有地心引力）
// 慢慢走動     10 ～ 13
// 用力搖一下   15 ～ 25
2

最直覺的寫法會出錯

超過門檻就加步數？加速度計一秒送 50 筆，搖一下有 5～10 筆都超過門檻，步數會一次暴增。

// ✗ 錯誤示範：搖一下可能加 20 步
if (s.magnitude > 15) {
  _steps += 1 + _random.nextInt(3);
}
3

第一道防線：高峰只算一次

記住上一筆是不是已經在門檻之上。只有「從下面衝上來」的那一筆才算，掉回門檻以下才重新開放。

bool _above = false;

int feed(AccelSample s, DateTime at) {
  if (s.magnitude <= threshold) {
    _above = false;      // 掉下來了，下次可以再算
    return 0;
  }
  if (_above) return 0;  // 還在同一個高峰
  _above = true;
  …
}
4

第二道防線：冷卻時間

搖一下時數值會上下抖動，可能在門檻附近穿過好幾次。兩次搖晃至少隔 400 毫秒，人手不可能搖得更快。

DateTime? _last;

  …
  _above = true;
  if (_last != null && at.difference(_last!) < cooldown) {
    return 0;            // 太快了，當作同一次
  }
  _last = at;
  return 1 + _random.nextInt(3);
5

隨機 1～3 步

nextInt(3) 得到 0、1、2，加 1 才是 1、2、3。Random 從建構子傳進來，測試時給固定種子，結果就能重現。

class ShakeDetector {
  ShakeDetector({
    this.threshold = 15,
    this.cooldown = const Duration(milliseconds: 400),
    Random? random,
  }) : _random = random ?? Random();

  final Duration cooldown;

}

final d = ShakeDetector(random: Random(56));
6

接到檢測頁

偵測器只負責「這一筆加幾步」，累加和顯示交給畫面。開始檢測時歸零並 reset，卡路里用第 10 堂的 fmtKcal。

final _detector = ShakeDetector();
int _steps = 0;

void _start() {
  setState(() {
    _steps = 0;
    _detector.reset();
    _sub = Accel.stream().listen((s) => setState(() {
      _steps += _detector.feed(s, DateTime.now());
    }));
  });
}

// build
Text('$_steps', style: AppText.big),
Text('步・${fmtKcal(_steps)} kcal', style: AppText.label),
